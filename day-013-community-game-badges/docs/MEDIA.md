# 이미지와 검증 범위

`images/hero.webp`, `promotion.webp`, `feature-badge.webp`, `feature-flow.webp`는 제품 기능을 설명하는 생성 일러스트입니다. 실제 서비스 캡처나 Riot 인증·운영 랭크의 증거가 아닙니다. 그림에 있는 티어·LP·작성자는 예시입니다.

`popup-login.webp`, `popup-consent.webp`, `popup-rank-example.webp`는 실제 Windows Chrome 확장의 툴바 팝업에서 촬영했습니다. Day7 로컬 OIDC 엔진·합성 DC 계정·가상 Riot HTTP 응답·격리된 데이터 저장소를 사용했으며 실제 Riot 계정을 인증한 캡처가 아닙니다. 화면의 ‘DC Mock’과 가상 데이터 안내는 그 시험 조건을 표시합니다.

앱 아이콘과 작은 티어 표시는 이 프로젝트의 원본 벡터에서 만들었습니다. Riot나 DCInside의 공식 제품·제휴·승인 표시가 아닙니다. 공개 안내와 이미지 제공은 앱·서버 개발 소스 공개나 코드의 오픈소스 라이선스 부여를 의미하지 않습니다.
