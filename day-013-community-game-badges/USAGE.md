# 설치 후보 사용 안내 · 0.6.0

**출시 준비 중입니다. 실제 Riot API 연동은 아직 되지 않았습니다.** 이 ZIP을 설치해도 현재 실제 LoL 계정 소유권 인증·운영 티어 조회·배지 등록은 사용할 수 없습니다. Chrome 웹스토어에 게시된 제품도 아닙니다.

## 설치

1. [0.6.0 사전 공개 릴리즈](https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day013-extension-v0.6.0)의 `community-game-badges-0.6.0-chrome-preview.zip`을 받습니다.
2. ZIP을 전부 압축 해제해 보관할 폴더에 둡니다. ZIP 안에서 바로 실행하지 않습니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
5. 확장 이름이 **커뮤니티 게임 배지**, 버전이 **0.6.0**인지 확인합니다. Chrome 퍼즐 아이콘 메뉴에서 고정하면 팝업을 열기 쉽습니다.

ZIP에는 빌드가 끝난 실행 파일이 들어 있습니다. Node·Flutter·개발 소스나 Riot API 키를 따로 설치할 필요는 없습니다. 다만 운영 서버가 아직 준비되지 않았으므로 실제 게임 기능은 열리지 않습니다. 개발자 모드 설치는 압축 해제한 폴더를 계속 유지해야 합니다.

## 지금 확인할 수 있는 것

확장 설치와 버전, 요청 권한, 기본 팝업을 확인할 수 있습니다. 현재 팝업의 ‘서버에 연결하지 못했습니다’ 안내 또는 미등록 배지 상태는 운영 서비스가 개방되지 않은 상태와 관련이 있습니다. 이 안내를 없애려고 API 키·비밀번호를 입력하거나 비공식 서버로 연결할 필요는 없습니다.

실제 Riot 계정이 연결됐다는 예시 데이터는 제공하지 않습니다. 소개 페이지의 D4·88 LP와 로컬 캡처는 가상 데이터이며, 공개 ZIP에서 실제 랭크로 등록되지 않습니다.

## 운영 연동 후 사용할 흐름

배지를 보기만 하는 사람은 로그인하지 않습니다. 지원되는 DC 게시글 작성자가 공개한 랭크를 닉네임 옆에 표시하는 흐름입니다.

자기 티어를 등록할 때는 확장 아이콘 → DC 로그인 → 별도의 LoL 소유권 확인 → 해당 DC 계정 공개 동의 순서로 진행합니다. 게임 프로필 아이콘 변경과 서버 확인은 실제 Riot 연동 뒤 사용할 기능이며, 지금 운영에서 완료할 수 있다는 안내가 아닙니다. Google 로그인이나 브라우저 제한에서는 별도 인증 창으로 진행합니다.

## 권한과 데이터

`storage`는 공개 랭크 캐시, `activeTab`은 현재 지원 게시글 작성자 확인, `identity`는 별도 인증 창 복귀에 사용합니다. 사이트 접근 범위는 DCInside와 이 서비스의 관리 API·공개 랭크 저장소로 제한했습니다. 게시글 전체 URL·본문·댓글·방문 이력을 서버에 수집하는 용도가 아닙니다.

사용자가 공개에 동의한 커뮤니티 계정과 랭크만 배지에 표시하도록 구현했습니다. 게임의 비공개 공통 식별자나 다른 커뮤니티 연결 목록은 공개하지 않습니다. [개인정보처리방침](https://community-game-badges-20261022.web.app/privacy)

## 업데이트·제거

개발자 모드 설치의 새 버전은 새 ZIP을 별도 폴더에 풀고, 확장 관리 화면에서 기존 항목을 제거한 뒤 새 폴더를 다시 로드할 수 있습니다. 제거하면 확장의 로컬 캐시와 입력 초안 등이 삭제됩니다. 이미 운영 서버에 저장한 계정 연결이 생긴 뒤에는 브라우저 제거와 서버 계정 삭제가 별개이므로 서비스의 연결 해제·삭제 절차를 이용해야 합니다.

현재 후보에는 자체 자동 업데이트가 없습니다. 다른 Daily Odd Builds 제품의 ‘latest’ 파일이 아니라 이 제품의 명시된 릴리즈를 확인하세요.

## 파일 무결성

릴리즈의 `SHA256SUMS.txt`와 내려받은 ZIP의 SHA-256을 비교할 수 있습니다. Windows PowerShell 예:

```powershell
Get-FileHash .\community-game-badges-0.6.0-chrome-preview.zip -Algorithm SHA256
```

체크섬은 파일 무결성 확인이며 전자서명이나 스토어 심사 승인을 대신하지 않습니다. 설치 ZIP의 번들 JavaScript는 실행에 필요한 파일입니다. 개발 원본·서버 코드·소스맵은 제공하지 않습니다.
