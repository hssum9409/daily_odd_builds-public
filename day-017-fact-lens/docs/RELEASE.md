# 팩트렌즈 0.1.21 · Day 017

첫 ZIP 공개: 2026-11-01. 포털 Day 017의 기록 날짜는 챌린지 기준 2026-10-28입니다.

## 포함된 동작

ChatGPT 로그인·갱신, 페이지 본문·제목·이미지·댓글 읽기, 설정한 최대 4–20개 안에서 중요한 대주장 우선 선정, 최대 3개 병렬 웹 검증, 요약정리, 4개 출력 언어, Fast 기본값과 지원 거절 시 복구, 원문 이동·하이라이트, 선택형 오류 리포트를 제공합니다.

0.1.18에서 검색 도구의 출처·페이지 열기·인용 메타데이터를 처리하고 URL의 해시 부분 차이로 근거 연결이 사라지는 문제를 수정했습니다. 게시글 안의 링크에 한정하지 않는 외부 다중 검색 지시를 강화했습니다. 출처가 없는 첫 응답은 한 번 재검색하며 실제 검색 결과 없이 근거를 만든 것으로 처리하지 않습니다. 여러 출처 중 추적 가능한 유효 출처를 최대 8개 표시합니다. 이 출처 상한은 사용자 설정의 대주장 수와 별개입니다.

## 검증 범위

로컬 Node 24.19.0에서 구문·manifest 검사와 자동 테스트 **132개**를 통과했습니다. 원문 연결, 대주장 범위, 복합 주장, 사용자 최대 개수, 스트리밍·JSON·Fast 호환 처리, 모의 인증·갱신, 진단 필터와 외부 출처 재검색을 검사합니다.

Windows Chrome 156의 실제 확장 로딩·UI 자동 검사는 격리 프로필과 합성 페이지·모의 OpenAI 응답을 사용합니다. 이는 실제 사용자 계정의 신규 토큰 발급이나 해당 뉴스의 사실 판정을 입증하지 않습니다. 사용자 확인으로 실제 계정의 Fast 처리와 gpt-6.1-terra 정상 완료가 확인된 이력이 있지만 이번 아카라이브 글 재검증과는 구분합니다.

오류 서버는 로컬 Firestore 에뮬레이터에서 동시 접수·중복·제한·TTL·허용 필드 검사를 통과했습니다. 기존 배포에서 실제 Chrome의 합성 리포트 접수와 저장도 확인했으며 QA 문서는 제거했습니다. 이 검사는 팩트체크 모델 호출 성공을 의미하지 않습니다.

GitHub Actions를 사용하지 않습니다. 빌드·검사·ZIP 생성은 로컬에서 수행하며 배포 파일은 GitHub Releases에 직접 올립니다. 런타임은 ZIP 안의 `manifest.json` 폴더를 Chrome 개발자 모드로 로드합니다. 자동 업데이트는 없습니다.

## 미검증·한계

macOS·Linux, 다른 Chromium 브라우저, 모든 계정·모델·사이트 조합은 미검증입니다. Chrome 내부 페이지·PDF, 로그인·보안 정책으로 차단된 자료와 일부 동적 댓글·이미지는 읽지 못할 수 있습니다. AI의 논점 선정·OCR·요약·판정은 오류가 있을 수 있으며 독립적인 출처 확보를 보장하지 않습니다.

[설치·업데이트](INSTALLATION.md) · [전용 릴리즈와 SHA-256](https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day017-fact-lens-v0.1.21)

0.1.19는 Apache-2.0 라이선스 전문을 ZIP 내부와 공개 문서에 함께 포함한 배포 고지 보완입니다. 검색·로그인·판정 기능은 0.1.18과 같습니다. 기존 0.1.18 태그·파일은 교체하지 않습니다.

## 0.1.20

설정의 일반·만든놈 탭 아래 공통 영역에 작은 글씨의 [개인정보취급방침](https://daily-odd-builds-portal.web.app/privacy/fact-lens) 링크를 추가했습니다. 새 탭에서 공개 방침을 엽니다. 패널 하단에는 AI가 생성한 결과이며 정확성·사실 여부를 보장하지 않는다는 안내를 작은 글씨로 표시합니다. 페이지 처리·인증 권한·모델 호출 동작은 변경하지 않았습니다.

## 0.1.21

설정창의 닫기 버튼을 파란 배경·흰 글씨의 버튼으로 바꾸고 최소 64×36px 크기를 적용했습니다. 마우스를 올리거나 누를 때의 색상과 키보드 포커스 표시를 제공합니다. 일반·만든놈 탭에서 동일하게 사용할 수 있습니다.

이번 변경은 로컬 구문·manifest 검사, 실제 Chrome의 격리 프로필에서 버튼 표시·포커스·클릭·설정 복귀, ZIP 내용을 확인했습니다. 사용자 요청에 따라 링크 검증·OG 검사·카카오 검증은 수행하지 않았습니다.

## 0.1.21 소스 공개

설치본과 같은 버전의 확장·오류 리포트 서버·빌드/테스트 코드를 [source](../source/)에 MIT 라이선스로 공개했습니다. 비공개 개발 이력·인증정보·운영 데이터는 포함하지 않습니다. 기존 설치 ZIP과 릴리즈 태그는 교체하지 않습니다.

공개 소스 복사본에서 npm ci, 구문·manifest 검사, 단위 테스트 132개, 빌드·패키징을 통과했습니다. 재빌드 결과는 JavaScript 등 10개 파일이 기존 설치본과 바이트 일치하고 나머지 정적 파일 4개는 줄바꿈만 다릅니다. 오류 서버의 Firestore 에뮬레이터 테스트 2개도 통과했습니다. 독립적인 빌드·테스트 방법은 소스 README에 있습니다. 링크·OG·카카오 검증은 앞선 사용자 요청에 따라 진행하지 않았습니다.
