# 팩트렌즈 데이터 처리 안내

적용 버전 0.1.19 · 2026-11-01

## 페이지 읽기와 AI 처리

모든 사이트 접근 권한은 사용자가 확인할 페이지의 본문과 이미지·댓글을 읽고 원문 위치를 표시하기 위해 사용합니다. 방문 기록을 모아 서버에 전송하거나 방문만으로 본문을 자동 업로드하지 않습니다. 폼·입력창·작성 초안·숨겨진 요소 등은 읽기에서 제외하도록 처리합니다. 추출이 완벽하다고 보장하지 않으므로 전송 전 내용을 확인하세요.

사용자가 **팩트체크** 또는 **요약정리**를 실행하면 본문, 제목과 페이지 맥락, 선택해 포함한 댓글·이미지 등이 OpenAI로 전송됩니다. 이미지의 글자·내용 인식도 OpenAI에서 처리합니다. 팩트체크는 외부 웹 검색을 요청하며 요약정리에는 검색을 요청하지 않습니다. 모델과 검색 서비스의 처리에는 OpenAI의 정책·계정 설정이 적용됩니다. `store:false` 요청이 외부 서비스의 모든 로그 삭제를 보장하지는 않습니다.

## 로그인과 기기 내 저장

ChatGPT 로그인은 OpenAI 공식 화면에서 진행합니다. 확장은 PKCE를 사용해 코드를 토큰으로 교환하며 별도 로컬 서버를 실행하지 않습니다. 로그인 토큰은 Chrome 프로필의 확장 저장 영역에서 암호화해 보관하고 갱신합니다. 비밀번호를 수집하지 않으며 OpenAI 토큰을 팩트렌즈 오류 서버로 전달하지 않습니다.

모델·언어·Fast·최대 주장 수 등 설정은 Chrome 확장 저장소에 보관합니다. 로그인 해제는 기기의 연결 정보를 제거합니다. OpenAI 쪽 연결 권한은 해당 서비스의 연결 앱 관리에서도 철회할 수 있습니다. 확장 제거 또는 다른 Chrome 프로필로의 설치는 별도 로그인·설정 상태가 됩니다.

## 선택형 오류 리포트

리포트는 자동 전송하지 않습니다. 사용자가 **오류 리포트**에서 JSON 항목을 확인한 뒤 전송할 때만 Daily Odd Builds 프로젝트의 오류 서버로 보냅니다.

전송 항목은 임의 접수 UUID, 스키마·확장 버전, Chrome 주 버전, 단계·모델 이름·HTTP 상태·응답 형식·재시도·검색 출처 개수 같은 허용된 기술 진단 값입니다. **페이지 URL·제목·본문·댓글·이미지·생성 결과·계정·이메일·OpenAI 토큰·쿠키·임의 설명은 포함하지 않습니다.**

리포트는 Google Firebase 서울 리전에서 수신 후 30일이 지나면 삭제 대상이 됩니다. 실제 삭제는 비동기로 지연될 수 있습니다. 자체 남용 제한 기록은 원시 IP 대신 일별 HMAC 지문과 횟수를 사용하고 약 2일 뒤 삭제 대상이 됩니다. Google Cloud 자체 접속 로그에서는 IP·시각·상태 등 플랫폼 로그가 처리될 수 있으며 위 리포트 보존 기간과 다릅니다. 리포트 본문은 공개 조회되지 않습니다.

확장에 광고·분석 SDK는 포함하지 않습니다. 이 오류 서버는 페이지 AI 처리를 중계하지 않습니다.
