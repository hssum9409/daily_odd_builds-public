# 이미지와 캡처

대표·홍보·기능 설명은 이 제품을 위해 native 이미지 생성으로 만든 일러스트입니다. Day 1·2·3·7·8의 실제 공개 이미지를 참고했으며 제품의 페이지·사이드패널·근거·원문 이동을 설명합니다. 실제 뉴스, 실계정 로그인이나 검색 성공을 증명하는 캡처가 아닙니다.

| 파일 | 역할 |
| --- | --- |
| images/hero.webp | 대표 일러스트 |
| images/promotion.webp | 정사각형 홍보 일러스트 |
| images/feature-flow.webp | 핵심 논점 선정·근거 확인·원문 이동 설명 |
| images/ui-claims.webp | 실제 확장 UI, 합성 자료와 모의 응답의 결과 카드 |
| images/ui-summary.webp | 같은 영어 원문을 영어·일본어·중국어로 요약한 실제 UI 3화면 가로 배치, 합성 자료·모의 응답 |
| images/ui-settings.webp | 실제 확장 UI, 이전 버전의 일반 설정 · 모의 계정 |
| images/ui-reading-0.1.23.webp | Windows Chrome에서 촬영한 0.1.23 읽기 설정 · 모의 계정 |

스크린샷은 로컬 Chrome의 격리된 프로필에서 촬영했습니다. 타인의 기사·댓글·인증 정보는 포함하지 않습니다. 게시한 WebP는 원본 PNG를 보관한 상태에서 용도별로 축소·압축했습니다. 포털 공유 이미지는 대표 일러스트에서 비율을 유지해 만든 1200×630 WebP입니다.

제품 렌즈 아이콘은 코드로 만든 벡터이며 확장용 크기별 PNG를 함께 제공합니다. 설정 등 UI의 Lucide 아이콘을 비롯한 외부 코드·자산의 고지는 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)를 확인하세요. 이 페이지가 제품 전체에 별도 오픈소스 라이선스를 부여하지는 않습니다.

요약 이미지는 0.1.21 확장을 격리 Chrome에서 언어별로 실행해 캡처한 뒤 한 장에 배치했습니다. 각 화면의 언어 이름과 하단 설명은 캡처 밖의 비교용 표기이며 확장 기능으로 추가된 UI가 아닙니다. 실계정 모델의 번역 품질 검증을 의미하지 않습니다.
