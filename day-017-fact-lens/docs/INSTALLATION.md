# 팩트렌즈 설치·업데이트

이 확장은 Chrome 웹 스토어 대신 ZIP 파일로 배포합니다. 별도 로컬 서버·Node.js·API 키가 필요하지 않습니다.

## 처음 설치

1. [0.1.18 ZIP 다운로드](https://github.com/hssum9409/daily_odd_builds-public/releases/download/day017-fact-lens-v0.1.18/fact-lens-0.1.18.zip).
2. 계속 보관할 폴더에 압축을 풉니다. 예: `문서/팩트렌즈`. 파일 탐색기에서 ZIP 안을 열어 보기만 하는 것으로는 설치되지 않습니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. `manifest.json`, `background.js`, `sidepanel.html`이 바로 들어 있는 압축 해제 폴더를 선택합니다.
7. 확장 메뉴에서 **팩트렌즈 — 페이지 팩트체커**를 고정합니다. 사이트 접근은 **모든 사이트에서**로 허용합니다.
8. 확인할 일반 웹페이지로 돌아가 아이콘을 누릅니다. **ChatGPT로 로그인**을 누르고 열린 OpenAI 공식 페이지에서 직접 로그인·동의를 완료합니다. 요금제 사용 연결이 필요할 수 있습니다.
9. 패널에 돌아와 모델을 고르고 전송 내용을 확인한 뒤 **팩트체크** 또는 **요약정리**를 누릅니다.

[Chrome 공식 수동 설치 설명](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## 업데이트하면서 로그인·설정 유지

1. [팩트렌즈 전용 릴리즈](https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day017-fact-lens-v0.1.18)의 ZIP을 받습니다. 저장소 전체의 Latest는 다른 Day일 수 있습니다.
2. **처음 설치에 사용한 같은 폴더**에 새 파일을 덮어씁니다.
3. `chrome://extensions`에서 기존 팩트렌즈의 **새로고침**을 누르고 패널을 다시 엽니다.

일반적으로 같은 폴더에서 새로고침하면 확장 ID와 Chrome 프로필의 로그인·설정을 유지합니다. **기존 확장을 제거하거나 새 폴더에서 별도 확장으로 설치하면 다시 로그인해야 할 수 있습니다.** 계정 연결 만료·철회 시에도 재로그인이 필요합니다. 확장 폴더는 계속 보관해 주세요. ZIP 설치에는 자동 업데이트가 없습니다.

## 자주 막히는 곳

| 현상 | 확인할 것 |
| --- | --- |
| manifest를 찾지 못함 | ZIP을 먼저 풀고, 파일이 바로 들어 있는 폴더를 선택했는지 확인합니다. |
| 본문 접근 권한 오류 | 확장의 사이트 접근을 모든 사이트로 허용한 후 페이지와 확장을 새로고침합니다. Chrome 내부 페이지와 PDF는 지원하지 않습니다. |
| 페이지가 바뀌었는데 이전 글이 보임 | 상단 **페이지 내용 반영하기**를 누릅니다. |
| 로그인 기능만 보임 | ChatGPT 연결을 완료해야 기능을 사용할 수 있습니다. |
| 모델·검색·이미지 오류 | 계정의 지원 모델·기능과 사용 한도를 확인합니다. 오류 리포트는 전송 항목을 확인한 뒤 보낼 수 있습니다. |
| 학교·회사 기기에서 개발자 모드 차단 | 해당 기기의 관리자 정책을 따릅니다. 정책 우회 설치는 제공하지 않습니다. |

시크릿 모드는 지원하지 않습니다. 로그인에 필요한 외부 창은 직접 조작하세요. 비밀번호·쿠키·토큰을 제보에 포함하지 마세요.
