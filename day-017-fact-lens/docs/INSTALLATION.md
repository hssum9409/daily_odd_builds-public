# 팩트렌즈 설치·업데이트

## Chrome 웹 스토어에서 설치

1. [Chrome 웹 스토어의 팩트렌즈](https://chromewebstore.google.com/detail/mfiomjajfkfkdbchdfegfofklpplpmcc)를 엽니다.
2. **Chrome에 추가**를 누르고, 권한 안내를 확인한 뒤 **확장 프로그램 추가**를 누릅니다.
3. Chrome 도구 모음의 확장 메뉴에서 **팩트렌즈 — 페이지 팩트체커**를 고정합니다.
4. 확인할 일반 웹페이지를 열고 팩트렌즈 아이콘을 누릅니다.
5. **ChatGPT로 로그인**을 눌러 열린 OpenAI 공식 화면에서 로그인·동의를 완료합니다.
6. 페이지 제목과 전송할 내용을 확인한 뒤 **팩트체크** 또는 **요약정리**를 누릅니다.

## 업데이트

Chrome이 스토어에 공개된 새 버전을 확인하고 자동으로 업데이트합니다. 적용이 늦으면 팩트렌즈 패널을 닫고 Chrome을 다시 시작해 보세요. [Chrome 공식 업데이트 안내](https://developer.chrome.com/docs/extensions/develop/concepts/extensions-update-lifecycle)

## 기존 개발판에서 옮기기

스토어에서 설치한 팩트렌즈를 열어 ChatGPT에 다시 로그인하고 원하는 설정을 적용합니다. 개발자 모드로 설치했던 판과 스토어판은 별도의 확장으로 설치되어 로그인·설정이 자동으로 옮겨지지 않을 수 있습니다.

두 판을 함께 설치했다면 Chrome 확장 관리 화면에서 앞으로 사용할 판을 확인하고 다른 판을 사용 중지할 수 있습니다.

## 자주 막히는 곳

| 현상 | 확인할 것 |
| --- | --- |
| 스토어에서 설치 버튼이 보이지 않음 | 데스크톱 Chrome에서 스토어 페이지를 열었는지 확인합니다. 관리 기기라면 설치 정책을 확인합니다. |
| 본문 접근 권한 오류 | 확장 세부정보에서 사이트 접근을 확인하고 페이지와 확장을 새로고침합니다. |
| 페이지가 바뀌었는데 이전 글이 보임 | 상단 **페이지 내용 반영하기**를 누릅니다. |
| 로그인 기능만 보임 | ChatGPT 연결을 완료합니다. |
| 모델·검색·이미지 오류 | 계정의 지원 모델·기능과 사용 한도를 확인합니다. 오류 리포트는 전송 항목을 확인한 뒤 보낼 수 있습니다. |
| 개발판과 스토어판이 함께 표시됨 | 사용할 판을 확인하고 해당 판의 아이콘을 고정합니다. |

시크릿 모드는 지원하지 않습니다. Chrome 내부 페이지·PDF 등 접근할 수 없는 페이지가 있습니다.
