## 집계 방법

- Codex 세션 로그의 `token_count` 이벤트에서 고유 세션별 **마지막 누적 `total_token_usage`**를 한 번만 사용합니다.
- 재개된 같은 세션이 여러 파일에 있어도 파일별 누적값을 합산하지 않습니다.
- 합계는 입력 + 출력입니다. **캐시 입력은 입력에, reasoning은 출력에 이미 포함**되어 있어 다시 더하지 않습니다.
- 긴 작업에서 같은 문맥을 반복 읽은 사용량을 포함합니다. 이 수치는 새로 생성한 글자 수·현재 문맥 크기·결제액과 다릅니다. 별도 이미지 생성량을 텍스트 토큰으로 환산하지 않습니다.
- 원본 로그, 대화 내용, 세션 식별자, 계정 정보와 파일 경로는 공개하지 않고 집계값과 방법만 제공합니다.
