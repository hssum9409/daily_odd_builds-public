# 아트워크 제작 기록

GPT-6 Astra / High 별도 작업자가 참고 이미지를 열어 보고 내장 이미지 생성 도구를 직접 호출했습니다. Astra는 이미지 생성 호출을 수행한 작업자의 모델이며, 이미지는 내장 이미지 생성 도구의 결과물입니다. API 키를 받거나 외부 이미지 생성 CLI를 사용하지 않았습니다.

## 공통 방향

Daily Odd Builds Day 001·002·003·005의 큰 한국어 타이포그래피, 넓은 여백, 부드러운 제품 카드와 입체감을 참고했습니다. Day 006은 파란색 `#3B4890`, 짙은 남색, 흰색과 옅은 청색을 사용합니다. 다른 Day의 캐릭터·마스코트·앱 화면, 타사 로고와 공식 제휴 표현은 사용하지 않습니다. 현재 서비스의 설명용 이름 `DC 계정 인증 / SSO`를 유지하며 새 브랜드나 개발자 경고문을 만들지 않습니다.

## 대표 이미지 프롬프트 요약

가로형 한국어 서비스 소개. 제목 `DC 계정 인증 / SSO`, 큰 문구 `내 서비스에 디시 인증을 연결하세요`, 설명 `계정 인증 API · 통합 로그인`, Day 006과 서비스 주소를 배치합니다. 오른쪽에 흰색 로그인·정보 제공 동의 카드와 외부 서비스 A/B를 연결해 인증 상태 재사용을 설명합니다. 실제 계정·코드·토큰·Secret을 넣지 않으며 `기능 소개용 그래픽`으로 표시합니다.

## 연동 소개 이미지 프롬프트 요약

같은 파란색·타이포그래피로 `내 서비스에 맞는 두 가지 연동`을 설명합니다. 왼쪽은 `SSO / OIDC`와 `디시 인증 신원으로 로그인`, 오른쪽은 `계정 인증 API`와 `기존 회원에게 인증 연결`입니다. 공통 옵션 `인증 여부만 제공`, `식별 코드까지 제공`, `사용자 동의 후 제공`을 구분해 배치합니다. 미지원 커뮤니티나 게임·랭크 기능, 보안성에 대한 절대적 보장을 추가하지 않습니다.

## 추가 홍보·기능 이미지 프롬프트 요약

- `promo-cover`: `DC 계정 인증 / SSO`, `내 사이트에도 디시 인증 로그인`을 크게 배치한 가로 포스터입니다. SSO 통합 로그인과 API의 기존 회원 연결을 구분하고 서비스 주소를 넣습니다.
- `feature-overview`: `로그인부터 계정 연결까지` 아래에 SSO/OIDC, 계정 인증 API, 제공 정보 선택을 세 패널로 배치합니다. 인증 여부만 또는 식별 코드까지 제공하는 두 범위와 사용자 동의를 표시합니다.
- `verification-flow`: `내 디시 계정인지는 공개 방명록으로` 아래에 로그인, 일회용 코드 발급, 사용자의 공개 방명록 작성, 소유권 확인을 순서대로 설명합니다. DC 비밀번호·로그인 쿠키를 받지 않는다는 현재 동작을 표시합니다.

새 세 장은 기존 포스터의 파란색·입체 카드·한국어 타이포그래피를 이어갑니다. 공개 포털 발표일과 개발 프로젝트 번호가 달라 새 이미지에는 Day 번호·날짜를 넣지 않았습니다. 갱신되는 토큰 집계도 이미지에 고정하지 않고 [별도 기록](TOKEN-USAGE.md)에 둡니다.

한글 문구와 기능 구분을 확인했습니다. 생성 원본과 PNG를 보존하며 WebP는 시각 편집 없이 무손실 형식 변환만 수행했습니다. 이 자료는 설명용 홍보 그래픽이며 실제 제품 화면의 기준은 [원본 캡처와 검증 범위](README-MEDIA.md)입니다.

## 2026-10-27 · 대표 이미지와 공개 번호

`images/hero-20261027.webp`는 새 README 대표 이미지입니다. GPT-6 Astra / High 아트 작업자가 기존 공개 Day 1·2·3·7·8 픽셀과 이 제품의 동의·인증 흐름을 확인하고 내장 imagegen을 직접 호출했습니다. 기존 `promo-cover.webp`는 별도 홍보 포스터로 README에 유지합니다.

새 hero에는 Day 번호를 넣지 않았습니다. 옛 `hero.webp`의 DAY 006은 과거 제작 번호이며, 현재 공개 포털 번호는 Day 007입니다. 옛 파일을 현행 대표 이미지로 연결하지 않습니다. 생성 PNG·프롬프트는 제작 기록에 보존하며 공개 WebP는 같은 크기의 무손실 변환입니다.

High는 작업자의 reasoning 설정입니다. 이미지 backend 모델·품질·과금 등급은 도구에 노출되지 않았으며, 이전의 non-fast 표기를 backend 등급의 독립 검증으로 읽지 않도록 정리했습니다. 이미지 공개는 앱·서버 원본의 소스 라이선스 부여가 아닙니다.
