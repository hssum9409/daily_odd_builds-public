# 이미지 출처와 검증 범위

2026-10-22 · Day 006 · 공개 MVP 0.1.0

Day 001의 대표 이미지와 빠른 시작, Day 002의 가로 홍보물과 실제 UI 예시 구분, Day 003의 파란색·큰 제목·입체 카드, Day 005의 여백과 제품 중심 구성을 참고했습니다. 다른 Day의 캐릭터·로고·앱 화면을 Day 006의 기능으로 사용하지 않았습니다.

| 이미지 | 제작 방식과 범위 |
| --- | --- |
| `hero.png`, `hero.webp` | GPT-6 Astra High 작업자가 non-fast 설정으로 내장 이미지 생성 도구를 직접 호출해 제작한 가로 홍보 이미지. 로그인·동의 카드와 외부 서비스는 기능을 설명하는 생성 연출이며 실제 인증 성공 화면이 아닙니다. |
| `integration-intro.png`, `integration-intro.webp` | 같은 작업자가 같은 방식으로 제작한 두 연동 방식의 설명용 그래픽. SSO의 서비스 로그인과 REST의 기존 회원 연결을 구분합니다. |
| `flow-01.jpg` | 기본 버튼 → 로그인 → 인증 여부 제공 동의 → 외부 서비스 로그인. 실제 로컬 OIDC 엔진과 Emulator/DC Mock 신원의 브라우저 캡처 네 장을 배치한 모음입니다. |

생성 PNG는 보존하고 README에는 무손실 WebP를 사용했습니다. 두 형식의 크기와 디코딩 RGBA 픽셀 일치를 확인했습니다. 홍보 이미지의 제작 방향은 [아트워크 기록](ARTWORK.md)에 정리했습니다.

캡처 원본은 2026-10-21에 촬영했습니다. 테스트 계정·주소·시각은 예시이며 운영 사용자·비밀번호·토큰·Client Secret·일회용 인증 코드는 포함하지 않았습니다. UI 캡처를 AI가 다시 그린 이미지로 대체하지 않았습니다. 실제 Google·DC 소유권 인증 또는 모바일 실기기 검증을 이 캡처가 증명하는 것은 아닙니다.

2026-10-22 운영 HTTPS에서 네 가지 **화면 체험**, 동의 취소, Chrome 팝업 완료, 캡처 16장 로딩과 ZIP, SSO/REST 서버 예제 다운로드를 확인했습니다. 웹의 체험은 실제 인증 API에 연결하지 않는 UI 시뮬레이션입니다. 실제 사용자 인증과 구분하세요.
