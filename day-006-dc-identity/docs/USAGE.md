# 사용자 안내

[서비스 열기](https://dc-identity.web.app/) · [소개](../README.md)

Google 로그인 또는 아이디·비밀번호 회원가입으로 시작합니다. 서비스 로그인과 DC 소유권 인증은 별도 상태입니다. 서비스에 로그인한 뒤 내 계정에서 본인의 갤로그 식별 코드를 입력하고 인증을 시작하세요.

화면에 표시된 일회용 코드를 지정된 인증용 방명록에 **본인의 DC 계정으로 로그인한 상태에서 새 공개 글**로 작성합니다. 비밀글과 답글은 사용하지 않습니다. 돌아와 인증 확인을 누르면 서버가 코드를 확인합니다. 만료되면 새 코드를 발급받으세요. 다른 사람의 코드를 복사해도 작성자 식별자가 다르면 인증되지 않습니다.

DC 비밀번호·로그인 쿠키를 이 서비스에 입력하지 않습니다. DC 로그인은 DC 사이트에서 직접 수행합니다. 닉네임이나 유동닉/IP는 소유권 식별자로 사용하지 않습니다.

외부 서비스가 로그인을 요청하면 해당 서비스 이름과 정보 제공 범위를 확인합니다. 인증 여부만 제공하는지 식별 코드까지 제공하는지 확인하고 동의하거나 취소하세요. 연결 해제·재인증·탈퇴는 내 계정에서 진행합니다. 탈퇴는 해당 서비스 계정과 연결 정보를 정리하는 동작이며, 외부 사이트에 이미 저장된 회원 데이터는 그 사이트의 탈퇴 절차를 따릅니다.

아이디 찾기·비밀번호 재설정은 이전에 연결한 DC 계정의 새 방명록 증명을 요구합니다. Google 전용 계정은 Google 복구 절차를 사용합니다. DC 계정에도 접근할 수 없는 경우에는 소유권 증명을 우회해 복구하지 않습니다.

화면과 흐름만 확인하려면 [화면 체험](https://dc-identity.web.app/examples/)을 이용하세요. 체험 화면에는 실제 비밀번호나 인증 코드를 입력하지 않습니다.
