# 이미지와 코드의 범위

지피쨩 캐릭터를 참고해 이 프로젝트용으로 생성한 일러스트입니다. GPT-6 Astra / High 작업자가 실제 캐릭터 및 공개 Day 1·2·3·7·8 이미지를 열람하고 native image generation으로 만들었습니다. 공개 이미지 참조 커밋은 `3ce75dac4a043af4fc78c62bfb9c6d87fa19439f`입니다.

- `docs/images/hero.webp`: 가로 소개 이미지
- `docs/images/promotion.webp`: 정사각 홍보 이미지
- `docs/images/feature.webp`: 본문→퀴즈→인용 설명 이미지
- `extension/assets/gpichan-quiz.png`, 아이콘: O/X 진행자
- `extension/assets/gpichan-wiki-guide.webp`: 문서 외 탭의 책 든 안내 캐릭터
- `docs/images/ui-*.webp`: 실제 확장 HTML을 Chrome에서 실행한 화면. 합성 본문·계정·모델 응답을 사용한 예시

생성 일러스트는 실제 사이트·계정 사용 화면이 아닙니다. 이미지 생성 백엔드·별도 과금 등급은 도구가 공개하지 않아 확인하지 않았습니다. 원본 캐릭터 시트·참조 캐시·개인 생성 기록은 포함하지 않습니다.

루트 MIT 라이선스는 코드와 문서에 적용되며 캐릭터·아이콘·생성 일러스트를 별도 포괄 허가하거나 제3자의 상표·캐릭터 권리를 부여하지 않습니다. OpenAI·나무위키 공식 로고나 공식 제품이라는 표시는 아닙니다.

0.1.7의 `ui-ready.webp`는 2026-11-05 로컬 회귀 검사에서 실행한 실제 확장 HTML의 준비 화면(440×950)을 손실 없는 WebP로 변환한 캡처입니다. 본문·OAuth·모델은 합성 자료이며, 제거한 수동 갱신 버튼이 없는 현재 화면을 반영합니다. 기존 hero·promotion·feature 일러스트는 재사용했습니다.
