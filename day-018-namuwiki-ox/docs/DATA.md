# 데이터 처리와 본문 범위

공개 [개인정보취급방침](https://daily-odd-builds-portal.web.app/privacy/namuwiki-ox)은 설정의 일반/만든놈 탭 공통 하단에서도 열 수 있습니다. 정책·제작자·나무위키 바로가기 링크는 사용자가 누를 때 해당 웹사이트를 새 브라우저 탭으로 엽니다.

확장의 통신 대상은 인증용 `auth.openai.com`, 모델용 `api.openai.com`입니다. 나무위키 본문은 사용자가 열어 둔 탭에서 Chrome의 isolated world로 읽고, 확장이 나무위키나 외부 출처를 별도로 요청하지 않습니다. OAuth용 `http://127.0.0.1/*` 권한은 자신의 로그인 탭 콜백 관찰에만 사용하며 로컬 서버를 실행하지 않습니다.

문서·탭이 바뀌면 현재 나무위키 본문을 확장 안에서 자동으로 읽어 다음 출제 대상으로 준비합니다. **퀴즈 만들기**를 누르면 그때 준비된 문서 제목, 추출한 본문 구간과 소제목, 선택한 문제 수를 OpenAI로 전송합니다. 출제를 시작한 뒤 문서나 탭을 바꿔도 해당 퀴즈의 본문과 진행 상황은 유지합니다. 문서 이동만으로 모델을 호출하지 않습니다. 통상 출제 1회와 정답·해설 대조 1회로 구성됩니다. Fast/JSON 형식 거절에는 호환 재요청이 생길 수 있습니다. 모델 요청에는 `store: false`를 지정하며 검색 도구·검색 출처·페이지 이미지·쿠키·폼 입력·브라우저 이력을 첨부하지 않습니다. 이 옵션만으로 OpenAI 자체 보관 정책 전체가 바뀌는 것은 아닙니다.

본문은 `.wiki-content` 또는 실제 `s-1` 등의 절 앵커와 Vue 렌더러 경계로 확인된 본문 안의 표시된 텍스트를 DOM 순서로 추출합니다. `document.body` 전체로 범위를 넓히지 않으며, 본문 경계를 식별하지 못하면 중단합니다. 현재 나무위키의 해시 CSS 클래스명을 고정값으로 사용하지 않습니다. 숨김·접힌 문단·각주·목차·메뉴·폼·편집 영역·iframe 등은 제외합니다. 외부 링크의 표시 텍스트가 문장에 포함될 수 있으나 그 주소를 따라가거나 독립 출처로 취급하지 않습니다. 이미지 OCR과 이미지 다운로드는 수행하지 않습니다. 문항당 근거는 정확한 단일 구간 인용으로 제한합니다. 2차 편집 단계에서 정답·해설을 확인하고 잘못되거나 애매한 초안을 고치거나 교체합니다. 인용·개수·형식 검사 실패에는 편집을 자동 재요청하며, 정상적인 경우 생성 1회와 편집 1회, 편집 복구가 필요한 경우 최대 생성 1회와 편집 3회를 요청합니다. 취소·인증 오류·네트워크 오류는 반복하지 않습니다. 정확한 본문 인용과 문항 수 검사는 유지합니다.

| 저장 위치 | 내용 | 수명 |
| --- | --- | --- |
| 확장 IndexedDB | AES-GCM 암호화된 access/refresh token, 계정 이름·ID·scope, 비추출 키 | 연결 해제 또는 확장 제거까지 |
| `chrome.storage.local` | 모델·Fast·문제 수, 공개 client ID·host ID·동일 계정 확인용 subject, 토큰 갱신 일정 | 해당 프로필에 유지 |
| `chrome.storage.session` | 진행 중 PKCE/로그인 시도, 창별 출제 본문·문제·답·점수·진행 위치 | 브라우저 세션; 로그아웃 시 해당 확장의 퀴즈 전부 삭제 |

동기화 저장소·자체 수집 서버·원격 분석·신고 기능이 없습니다. 콘텐츠 스크립트에는 Chrome 저장소 접근을 허용하지 않습니다. 토큰을 패널 요청으로 전달하는 메시지는 확장 자체의 패널·인증결과 페이지로 제한합니다. 다른 앱·Day의 인증정보를 읽거나 복사하지 않습니다.

로그아웃은 로컬 인증 삭제를 먼저 완료하고 OpenAI의 refresh token 취소를 시도합니다. 원격 취소를 확인하지 못하면 화면에 구분해 표시합니다. client ID와 host ID 등 재연결 정보는 남습니다. 완전 초기화는 확장을 제거합니다. 기기 전체/Chrome 프로필을 점유한 프로그램으로부터 보호하는 OS 키체인은 아닙니다.
