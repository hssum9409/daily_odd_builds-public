# 0.1.5 ZIP preview

포털 Day 018 기록일은 2026-10-29이며 첫 ZIP 공개일은 2026-11-01입니다. Chrome 웹 스토어 제출·자동 업데이트는 제공하지 않습니다.

## 포함한 기능

- 현재 나무위키 본문의 5–20문제 OX 퀴즈, 기본 10개
- ChatGPT 로그인, 기본 GPT-6.1 Terra·Fast 켜짐, 모델/옵션 변경
- 정확한 본문 인용과 정답·해설, 잘못되거나 애매한 초안의 자동 수정·교체
- 출제 단계·경과 시간·취소, 문서 내용 갱신, 문서 외 탭 안내
- 하단 고정 출제/다음/결과 버튼과 위쪽 내용 스크롤
- 전체 패널 설정, 색상 있는 고정 닫기 버튼·Esc 복귀, 일반/만든놈 탭
- 채점·같은 문제/오답 복습·같은 브라우저 세션의 이어 풀기

## 로컬 검증

Windows, Node.js 24.19.0, 설치된 Chrome, Playwright 1.64.1에서 검사했습니다. GitHub Actions는 사용하지 않았습니다.

| 명령·검사 | 결과와 범위 |
| --- | --- |
| `npm ci --ignore-scripts` | 고정된 개발 의존성 설치 |
| `npm run check` | 구문·Manifest 권한·CSP·실행 파일 참조 검사 |
| `npm test` | 44개 통과: PKCE/콜백/ID 토큰 검증·암호화·세션/갱신·문항/근거·자동 수정·Fast 호환 |
| `npm run test:browser` | 합성 본문·OAuth·모델을 사용한 실제 확장 HTML의 로그인→출제→10문항/채점→복습→갱신/복구→취소→로그아웃 검사 |
| 실제 페이지 | 실제 나무위키 고양이 HTTP 200, section-renderer 149구간·59,700자 추출, 모델 요청 0회 |
| UI | 440×950·320×560·320×850, 전체 패널 설정과 상단 닫기, 퀴즈 복귀, 하단 고정 버튼·스크롤, 관련 JS 오류 없음 |
| `npm run package` | 원본·dist·ZIP의 파일 목록·모든 바이트 일치, ZIP CRC와 SHA-256 |
| 공개 소스 | 공개할 스냅샷에서 별도로 의존성 설치·검사·빌드·패키징. 실행 ZIP과 바이트 일치 확인 |

전체 Chrome 회귀 후 변경한 설정 헤더 스크롤 여백은 별도 Chrome 검사로 확인했습니다. 공개용 화면에는 같은 확장 UI와 짧은 합성 해설을 사용했습니다. 생성 일러스트와 실제 확장 HTML의 합성 자료 화면은 README에서 구분합니다.

실제 ChatGPT 계정의 최초 동의·계정별 모델 목록·Terra 요청·Fast 실효 등급은 위 합성 검사로 입증되지 않습니다. 실제 계정 권한, macOS 실기기, 모바일 Chrome, Chrome 웹 스토어 설치, 툴바로 여는 네이티브 사이드패널 표면은 별도 검증 범위입니다. 모델의 의미 판단에는 오류가 있을 수 있습니다. 접근 확인·로그인 제한을 우회하지 않습니다.
