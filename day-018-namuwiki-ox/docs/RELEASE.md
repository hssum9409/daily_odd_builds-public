# 0.1.10 · 계정 모델 자동 선택과 추론 설정 · 2026-11-06

확장 이름을 **나무위키 OX 퀴즈**로 변경했습니다.

로그인한 계정의 모델 목록에 GPT-6.1 Terra가 있으면 우선 선택하고, Terra가 없고 GPT-6 Luna가 있으면 Luna를 선택합니다. 두 모델 모두 기본 추론 수준은 Medium이며 Fast는 켜져 있습니다. 설정에서 모델·추론 수준·Fast를 바꿀 수 있습니다.

ChatGPT 로그인 응답에는 구독 등급이 제공되지 않습니다. 출제 권한과 모델 선택은 계정이 부여한 권한과 모델 목록에 따릅니다. Fast 요청이 거절되면 일반 처리로 재시도합니다.

- 정적 검사, 단위 테스트 44개, 격리 Windows Chrome에서 합성 OAuth·본문·모델 흐름을 확인했습니다. Terra 우선, Luna 차선과 Medium·Fast 요청, 수동 설정 보존을 검사했습니다.
- 로컬 원본·dist·설치 ZIP의 28개 파일을 비교했습니다. 공개 소스에서 설치 ZIP을 동일하게 재현했습니다.
- 실제 ChatGPT 구독 계정의 모델 호출과 Chrome 웹 스토어 설치는 이번 검증 범위 밖입니다.

기존 설치 폴더에 새 파일을 풀고 Chrome 확장 관리 화면에서 새로고침하세요.

# 0.1.7 · 문서 자동 반영 · 2026-11-05

문서·탭이 바뀌면 다음 출제 대상을 자동으로 읽습니다. 출제 중이거나 풀고 있는 퀴즈는 기존 본문·답·진행 위치를 유지하며 나무위키 밖에서도 계속 진행합니다. 결과 화면도 유지하고, 새 퀴즈 준비 화면에서만 나무위키 안내 에셋을 표시합니다. 문서 변경 안내와 갱신·다시 읽기 버튼은 제거했습니다.

## 이번 버전 검증

- Windows의 설치된 Chrome과 Playwright 1.64.1 격리 프로필에서 합성 나무위키·OAuth·모델 흐름을 검사했습니다. 개인 Chrome 프로필·쿠키·토큰을 사용하거나 복사하지 않았습니다.
- `npm run check`, `npm test` 44개, `npm run test:browser`를 통과했습니다. 문서/탭/클라이언트 이동 자동 반영, 출제 도중 이탈 후 원래 본문으로 완성, 다른 사이트에서 10문항·결과 진행, 답변 후 패널 재로드, 짧은 본문 자동 복구, 설정·취소·로그아웃을 검사했습니다.
- 문서 이동만으로 모델을 호출하지 않았으며 관련 JavaScript·콘솔 오류가 없었습니다. 440×950 및 320×560·320×850에서 하단 고정 버튼과 가로 넘침도 검사했습니다.
- `npm run package`로 동일 경로의 dist와 설치 ZIP을 갱신하고 원본·dist·ZIP의 28개 파일과 모든 바이트 일치를 확인했습니다. 공개 소스 스냅샷에서도 의존성 설치·검사·테스트·패키징을 수행했습니다.
- 실제 사용자 계정의 신규 로그인·모델 호출, 실제 사이트의 모든 이동 방식, macOS/Linux·모바일 Chrome·Chrome 웹 스토어 설치는 이번 합성 검사로 확인한 것으로 취급하지 않습니다. GitHub Actions를 사용하지 않았습니다.

기존 확장을 제거하지 말고 같은 설치 폴더에 새 파일을 교체한 뒤 Chrome 확장 관리 화면에서 새로고침하세요. 인증 저장 형식과 확장 경로는 유지합니다.

## 로컬 검증

Windows, Node.js 24.19.0, 설치된 Chrome, Playwright 1.64.1에서 검사했습니다. GitHub Actions는 사용하지 않았습니다.

| 명령·검사 | 결과와 범위 |
| --- | --- |
| `npm ci --ignore-scripts` | 고정된 개발 의존성 설치 |
| `npm run check` | 구문·Manifest 권한·CSP·실행 파일 참조 검사 |
| `npm test` | 44개 통과: PKCE/콜백/ID 토큰 검증·암호화·세션/갱신·문항/근거·자동 수정·Fast 호환 |
| `npm run test:browser` | 합성 본문·OAuth·모델을 사용한 실제 확장 HTML의 로그인→출제→10문항/채점→복습→갱신/복구→취소→로그아웃 검사 |
| 실제 페이지 | 실제 나무위키 고양이 HTTP 200, section-renderer 149구간·59,700자 추출, 모델 요청 0회 |

전체 Chrome 회귀 후 변경한 설정 헤더 스크롤 여백은 별도 Chrome 검사로 확인했습니다. 공개용 화면에는 같은 확장 UI와 짧은 합성 해설을 사용했습니다. 생성 일러스트와 실제 확장 HTML의 합성 자료 화면은 README에서 구분합니다.

실제 ChatGPT 계정의 최초 동의·계정별 모델 목록·Terra 요청·Fast 실효 등급은 위 합성 검사로 입증되지 않습니다. 실제 계정 권한, macOS 실기기, 모바일 Chrome, Chrome 웹 스토어 설치, 툴바로 여는 네이티브 사이드패널 표면은 별도 검증 범위입니다. 모델의 의미 판단에는 오류가 있을 수 있습니다. 접근 확인·로그인 제한을 우회하지 않습니다.
