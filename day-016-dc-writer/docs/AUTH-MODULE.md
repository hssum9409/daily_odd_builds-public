# ChatGPT 인증 모듈

공개 공통 모듈 `@daily-odd-builds/chatgpt-auth` 0.1.0을 고정 사용합니다.

https://github.com/hssum9409/daily_odd_builds-public/tree/chatgpt-auth-v0.1.0/packages/chatgpt-auth

버전과 포함 파일의 SHA-256을 `tools/verify-auth.mjs`로 확인합니다. 기존 디시 글쓰기 도우미의 프로필 저장소·모델 설정·패널 메시지 규약을 유지하며 다른 확장과 토큰을 공유하지 않습니다.

공개 Day 등록을 이유로 기존 설치 폴더를 옮기지 않습니다. 새 버전 파일을 같은 폴더에 교체하고 기존 확장을 새로고침합니다.
