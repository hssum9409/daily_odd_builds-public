# 설치·업데이트

ZIP preview를 전부 풀고 `chrome://extensions`에서 개발자 모드 → 압축해제된 확장 프로그램 로드를 선택합니다. `manifest.json`이 들어 있는 폴더를 로드합니다. 소스를 받은 경우 `extension/`입니다. 실행에는 Node나 Python이 필요 없습니다.

디시 PC 글쓰기 탭에서 확장 아이콘을 누릅니다. 원문 유지로 먼저 미리볼 수 있으며 AI 작성은 ChatGPT 로그인과 사용 권한 동의가 필요합니다. 로그인은 열린 공식 OpenAI 화면에서 직접 완료합니다. 사용할 모델은 계정의 목록에서 고릅니다.

업데이트 시 기존 폴더 위치를 유지하고 그 안에 새 실행 ZIP 파일을 교체한 뒤 기존 확장을 새로고침합니다. 폴더를 옮기거나 확장을 삭제 후 재설치하면 확장 ID와 저장된 연결에 영향을 줄 수 있습니다. 자동 업데이트와 Chrome 웹 스토어 배포는 제공하지 않습니다.

기존 개발판 사용자는 원래 로드한 `extension/` 폴더를 유지하세요. Day 등록을 위해 설치 폴더를 옮길 필요는 없습니다.

## 문제가 생기면

- 로그인 오류는 패널과 공식 로그인 탭의 안내를 확인하고 로그인 취소 후 다시 시도합니다. 계정의 동의 화면에서 이용 권한을 확인하세요.
- 확장이나 브라우저 재시작 후에도 같은 프로필의 유효한 연결은 복원합니다. 서버 해제·갱신 기한 만료·로컬 데이터 삭제 시 다시 로그인합니다.
- 글쓰기 탭이 없으면 PC 일반·마이너·미니 갤러리의 글쓰기 화면을 열고 대상 탭을 새로고침합니다.
- 편집기 내용이 바뀌었다는 오류는 사용자가 수정한 내용과 충돌하지 않도록 적용을 멈춘 것입니다. 편집기 상태를 다시 읽고 미리보기와 비교하세요.
- 업로드 완료가 불확실하면 초안을 보관하고 디시 글쓰기 탭을 새로고침합니다. 반복 클릭으로 중복 업로드하지 마세요.

연결 해제는 ChatGPT 연결만 지웁니다. 저장한 글과 사진은 설정의 **저장한 초안과 사진 삭제**에서 별도로 지웁니다. 디시 서버에 올라간 임시 첨부파일을 지우는 기능은 아닙니다.
