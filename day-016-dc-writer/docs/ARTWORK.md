# 아트워크와 캡처

hero.webp, promotion.webp, features.webp는 이 제품의 실제 UI와 Day 1·2·3·7·8의 소개 형식을 참고해 native 이미지 생성으로 제작한 기능 소개 일러스트입니다. 실제 게시 결과나 계정 성공 증거가 아닙니다.

ui-compose.webp, ui-preview.webp는 Windows Chrome 156에서 확장 UI를 실행한 실제 캡처이며 합성 자료·모의 인증/모델 응답을 사용했습니다.

공개 참고 자료 기준 커밋: 5735543a421e81dfbd9ef7ee315627533b366593. 각 이미지의 구성·문구·기능 순서와 최종 WebP를 검수했습니다. 소개 이미지는 소프트웨어 MIT 라이선스 적용 범위에서 제외합니다. 외부 제품의 상표 권리나 공식 승인 관계를 주장하지 않습니다.
