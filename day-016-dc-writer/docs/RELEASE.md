- 자동 추천은 계정 모델 목록에서 GPT‑6.1 Terra, GPT‑6 Luna 순으로 선택합니다. 두 모델의 자동 설정은 Medium과 Fast 켬입니다.

- AI 입력·출력 선두의 알려진 검증용 메모 표식 제거. 원문 유지 모드와 실제 인용 보존.
- 원문 유지·구조 정리·다듬어 쓰기·소재 작성, 미리보기·직접 수정·편집기 적용.
- 사진 기본 업로더, 기존 글 뒤 추가·확인 후 교체·제목/본문 되돌리기.
- 같은 프로필에 저장한 연결 복원과 갱신 토큰 10일 전부터의 자동 갱신.

Windows Chrome 156의 격리 프로필에서 로컬 정적 검사·단위 검사 44개·합성 일반 QA 26개·프로세스 재시작 QA 11개·백그라운드 QA 16개, 패키지와 고정된 인증 모듈의 해시를 검사합니다. 실제 Day 날짜만큼 기다린 검사는 아니며 제어된 기한 기록과 모의 응답으로 검사합니다.

이전 개발 중 사용자와 실계정 ChatGPT 로그인·동의·모델 생성·디시 편집기 적용을 확인했습니다. 기본 업로더의 실제 임시 사진 업로드도 별도로 확인한 이력이 있습니다. 새 프롬프트의 모든 실계정 모델·문체 품질, 실제 게시 완료, macOS/Linux·모바일·스토어 설치는 이번 합성 QA로 검증된 것이 아닙니다.

복구: 기존 설치 폴더를 보존한 채 이전 실행 ZIP의 파일을 교체하고 확장을 새로고침합니다. 연결 해제·확장 제거·데이터 삭제는 되돌릴 수 있는 단순 파일 교체와 다릅니다. 운영 서비스 변경에 따른 호환성 문제는 후속 버전에서 개선합니다.
