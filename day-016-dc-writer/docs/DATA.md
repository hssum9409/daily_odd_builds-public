# 데이터 처리

소재·제목·레퍼런스·지침·양식·사진 설명은 사용자가 AI 작성 기능을 실행할 때 OpenAI로 전송됩니다. 사진 분석 옵션을 켠 경우 새 로컬 사진의 축소본도 전송합니다. 기존 디시 사진은 임의로 내려받아 전송하지 않습니다. 원문 유지 모드는 AI 요청을 보내지 않습니다. 생성 요청에는 `store:false`를 사용하며 서비스 제공자의 별도 처리·보관 정책은 해당 약관을 따릅니다.

초안·사진은 자동 저장 설정에 따라 기기의 확장 전용 IndexedDB에 저장합니다. 양식·모델 선택·설정은 로컬 저장합니다. 별도 수집 서버·분석 SDK·Chrome 동기화는 사용하지 않습니다. 사진은 편집기에 적용할 때 디시 기본 업로더로 보냅니다.

ChatGPT 로그인은 공식 OpenAI 화면에서 진행합니다. access/refresh 토큰은 확장 프로필의 AES-GCM 암호화 저장소에 보관하며 키는 내보낼 수 없는 CryptoKey입니다. 같은 프로필에 키도 저장하므로 OS 자격 증명 저장소의 격리와 같지 않습니다. 프로필 전체를 장악한 공격에 대한 보호를 보장하지 않습니다. 다른 확장과 계정·토큰을 공유하지 않습니다.

연결은 Chrome 재시작 후 복원합니다. 마지막 발급·실제 교체 기준 30일짜리 갱신 토큰의 만료가 약 10일 남으면 일반 Chrome 창이 열린 동안 패널 없이 갱신을 시도합니다. 시크릿 창만 있거나 창 없이 프로세스만 실행 중이면 자동 갱신하지 않습니다. 30일간 갱신하지 못하면 만료를 허용합니다. 네트워크 오류에는 연결을 보존하고 재시도하며 서버가 무효화한 토큰은 재로그인을 안내합니다.

연결 해제 시 로컬 자격 증명을 삭제하고 최신 갱신 토큰의 원격 폐기를 시도합니다. 원격 폐기를 확인하지 못하면 안내합니다. 초안·사진은 설정에서 별도로 삭제합니다. 디시 업로드 파일의 서버 보관·삭제는 디시의 기능과 정책을 따릅니다.

권한: sidePanel(패널), scripting(선택한 디시 편집기 연결), storage(설정), tabs(대상·로그인 탭 관리), webRequest(이 확장이 연 로그인 콜백 감지), alarms(자동 갱신 예약). 사이트 접근 범위는 디시 PC 갤러리, OpenAI 인증/API, 자체 로그인용 loopback 콜백입니다. 로컬 콜백 서버를 실행하지 않습니다. 비밀번호·쿠키를 읽거나 게시 버튼을 자동으로 누르지 않습니다.
