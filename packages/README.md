# 공통 모듈

Daily Odd Builds 제품에서 실제로 함께 사용하는 코드입니다. 각 모듈은 자체 버전, 라이선스, 테스트와 사용 안내를 갖습니다. 앱 배포 ZIP에는 검증한 버전의 실행 코드를 포함하므로 별도 서버나 런타임 다운로드가 필요하지 않습니다.

| [chatgpt-auth](chatgpt-auth/) | 0.1.0 | Day 17 팩트렌즈, Day 18 나무위키 OX 퀴즈, 디시 글쓰기 개발판 | ChatGPT 로그인, 암호화 저장, 토큰 갱신, Chrome 인증 수명 관리 |
