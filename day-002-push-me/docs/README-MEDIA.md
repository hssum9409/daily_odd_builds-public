실제 Chrome 개인 예약의 탭 종료 후 알림 수신/클릭은 2026-10-13 사용자와 별도로 확인했습니다. 서버 sent/FCM 접수만으로 물리 기기 수신을 증명하지 않으며, 이 홍보 연출 이미지를 수신 증거로 쓰지 않습니다.

예시 UI는 콘서트 예매 대기 페이지 링크와 영양제 매일 반복 예약입니다. 두 갤러리 이름은 서비스 내 그룹의 예시입니다. 실제 이메일·계정 UID·등록 token·운영 초대 코드를 포함하지 않았습니다. 실제 Flutter UI를 Auth/Firestore emulator의 예시 계정/예약으로 새로 캡처했으며, 캡처에서 FCM 등록만 fixture로 대체하고 emulator 경고 overlay만 숨겼습니다. 운영 데이터 변경이나 실제 Push 발송은 없었습니다. 생성 이미지 내부의 앱 세부 텍스트는 원본 캡처와 차이가 있을 수 있으므로 기능 설명은 desktop/mobile 원본 예시를 기준으로 읽으세요.

홍보 이미지 6장의 프롬프트/색상/공개 범위는 [ARTWORK.md](ARTWORK.md)를 참고하세요. hero와 square의 예시를 콘서트로 수정하고 알림 클릭/기기 간 수신/그룹/매일 반복 소개를 추가했습니다. 생성 PNG를 그대로 보존하고 hero의 WebP는 무손실 형식 변환만 수행했습니다.
