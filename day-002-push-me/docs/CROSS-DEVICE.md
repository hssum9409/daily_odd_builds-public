# 컴퓨터에서 예약해 놓으면, 핸드폰에서도 딩동

![PC에서 예약하고 같은 계정의 등록된 휴대폰에서 받는 설명용 연출](images/cross-device.png)

컴퓨터에서 제목과 URL을 편하게 입력하고, 자리를 떠난 뒤에는 휴대폰으로 받습니다.

> **5분 뒤 콘서트 예매 시작!**<br>
> 눌러서 예매 대기 페이지로 바로가기

1. PC에서 Google로 로그인해 예약을 만듭니다. 이동할 예매 대기 페이지의 HTTP/HTTPS URL을 넣습니다.
2. 휴대폰에서도 **같은 Google 계정**으로 로그인합니다.
3. 휴대폰의 **알림 받기 → 허용**, 계정 메뉴의 **기기 등록 완료**를 확인합니다.
4. 다른 브라우저에서도 받고 싶다면 해당 브라우저에서 같은 설정을 합니다. 예약은 계정에 연결되고 Push는 등록된 기기로 전달합니다.

iPhone/iPad는 iOS/iPadOS 16.4+ 홈 화면 앱에서 로그인·등록해야 합니다. [설치 순서](USAGE.md#iphone--ipad). 브라우저/기기의 지원 여부를 확인하며 미지원 환경을 등록 완료로 표시하지 않습니다.

그림은 기기 간 흐름을 보여주는 연출입니다. 실제 iPhone 수신 검증 자료가 아니며 OS 설정·네트워크로 지연/누락될 수 있습니다. 알림에 원하는 예매 대기 페이지의 웹 주소를 넣어주세요.
