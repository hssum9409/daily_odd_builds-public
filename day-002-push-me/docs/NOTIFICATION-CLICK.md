# 알림을 누르면, 원하는 페이지로 바로

![콘서트 예매 Push를 누르면 예약에 지정한 예매 대기 페이지가 열리는 기능 설명용 연출](images/notification-click.png)

예매 시작 전에 알림을 받고, 알림을 눌러 미리 넣어둔 예매 대기 페이지로 이동합니다.

> **5분 뒤 콘서트 예매 시작!**<br>
> 눌러서 예매 대기 페이지로 바로가기

1. **새 알림**에서 제목·내용·날짜·시간을 입력합니다.
2. 선택 항목인 **이동 URL**에 원하는 예매 대기 페이지의 웹 주소를 넣고 예약합니다.
3. 도착한 **Push 알림을 누르면** 지정한 웹페이지가 열립니다. URL을 비워두면 푸시알림 띄워줘 화면으로 이동합니다.

콘서트 대기 페이지뿐 아니라 회의 접속 페이지, 이벤트 안내, 그룹 공지 링크에도 사용할 수 있습니다. 이동 URL은 **HTTP/HTTPS 웹 주소**만 허용합니다.

Chrome 개인 예약은 사이트 탭을 모두 닫은 뒤 실제 알림 도착과 클릭 시 지정한 example.com 페이지 이동을 확인했습니다. 그림의 콘서트 화면은 기능 설명용 연출이며 실제 예매 사이트 캡처가 아닙니다.
