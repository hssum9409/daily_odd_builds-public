# 데이터 처리 안내 초안

2026-10-14 현재 구현 사실을 설명하는 기술 안내입니다. 정식 개인정보 처리방침은 아닙니다. 운영자의 비공개 문의·삭제 접수 경로와 자동 보관 기간은 아직 확정되지 않았습니다.

| 데이터 | 처리 목적 / 위치 |
| --- | --- |
| Google 로그인 계정 정보 | Firebase Authentication에서 인증과 사용자 식별. 서비스가 Google 비밀번호를 직접 받지 않음 |
| 사용자 식별자와 생성 시각 | 사용자별 예약/기기 데이터 연결 |
| 기기 등록 token·플랫폼·브라우저 정보·갱신 시각 | 허용한 기기로 Push 전달, token 갱신과 등록 해제 |
| 알림 제목·내용·선택 URL·시각·시간대·상태 | 예약/발송/취소/내역 관리 |
| 그룹 이름·가입 정보·초대 정보 | 그룹 참여·권한·알림 대상 관리 |
| 기기 내 목록 캐시·버전·기기 식별값 | 같은 데이터를 반복 읽지 않고 화면 복원 |

인증·DB·Push·Hosting/예약 backend는 Google/Firebase 서비스를 사용합니다. 사용자 간 데이터는 인증과 Rules로 분리합니다. 그룹 멤버에게 그룹의 예약 내용은 보이지만 다른 멤버의 기기 token이나 서버 처리 기록은 공개하지 않습니다.

그룹에는 멤버 식별 코드(계정 UID)와 그룹 내 역할이 저장됩니다. 그룹장은 권한 관리에서 멤버 코드를 확인하고 관리자 역할을 부여·회수합니다. 이 기능을 위해 이메일이나 Google 프로필 이름을 새로 공유하지 않습니다. 멤버 코드는 해당 그룹장에게만 알려주고 공개 이슈에 올리지 마세요.

Push 제목/내용은 기기 설정에 따라 잠금 화면 등에 보일 수 있습니다. 민감한 개인정보를 알림에 입력하지 않는 편이 좋습니다. 이 초안/홍보 이미지에는 실제 계정·개인 예약·기기 token을 사용하지 않습니다.

## 취소·로그아웃·보관

- 예약 취소는 발송을 중단하는 기능이며 서버 기록 삭제 기능은 아닙니다.
- 로그아웃은 현재 브라우저 알림 등록을 해제하고 서비스의 목록 캐시를 정리합니다. 다른 기기/계정/서버 예약을 모두 삭제하지 않습니다.
- 최근 내역 30개는 화면/캐시 표시 상한입니다. 그 이전 서버 기록의 자동 삭제를 의미하지 않습니다.
- 전체 계정/서버 데이터 삭제 UI와 정해진 자동 보관 기간은 현재 구현하지 않았습니다. 공개 고지에서는 문의/삭제 절차를 실제 운영 방식에 맞춰 확정해야 합니다.

버그 제보는 [공개 Issues](https://github.com/hssum9409/daily_odd_builds-public/issues)에 브라우저/OS와 재현 순서를 적어주세요. 계정 이메일·UID·기기 token·인증 정보·개인 예약 내용은 공개 게시판에 올리지 마세요.
