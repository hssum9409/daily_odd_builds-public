# 매일 챙길 일은, 한 번만 예약하세요

![한 예약으로 오늘·내일·모레 반복하는 영양제 알림의 설명용 연출](images/daily-repeat.png)

> **영양제 먹어야 될 시간임**<br>
> 영양제 안먹는 습관좀 고쳐라 나 자신아...

1. 새 알림에서 제목·내용과 시작할 날짜/시간을 입력합니다.
2. **매일 반복**을 켜고 예약합니다.
3. 매일 같은 기준 시간대의 시각에 처리합니다. 반복 전체가 **예약 1건 / 슬롯 1개**로 유지됩니다.
4. 그만 받을 때는 발송 전 예약 메뉴에서 **취소**합니다.

개인 20개, 그룹당 20개 한도에서도 반복은 1건입니다. 처음 예약한 시간대를 유지하므로 다른 시간대로 이동했다면 원하는 기준으로 다시 예약하세요. 놓친 날짜의 알림을 몰아서 보내지는 않습니다.

그림은 반복 기능을 보여주는 알림 연출입니다. 실제 다음 날 반복 수신은 아직 실기기 검증 전이고, 발송/수신 시각은 서버 주기·네트워크·OS 상태에 따라 달라질 수 있습니다.
