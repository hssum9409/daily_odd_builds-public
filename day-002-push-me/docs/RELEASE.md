# Day 002 — 웹서비스 v1.0.0

2026-10-14 · Web / PWA · [서비스 열기](https://dingdong-to-me.web.app/) · [GitHub Release](https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day002-web-v1.0.0)

설치 파일 없이 웹에서 사용하는 서비스입니다. 공개 저장소에는 소개·사용법·구조 설명·홍보 이미지만 제공합니다. 앱/서버 원본, 운영 설정, 사용자 데이터와 비공개 개발 이력은 포함하지 않습니다. GitHub의 자동 Source code 압축 파일도 이 공개 저장소의 자료이며 Day 002 앱 소스 배포물이 아닙니다.

## 제공 기능

- Google 로그인, 기기별 알림 허용과 등록, 개인 예약 및 HTTP/HTTPS 링크 이동.
- 그룹 생성/초대 코드 참여, 그룹장 예약/취소, 멤버 목록 조회.
- 개인 20개·그룹별 20개·그룹 가입 2개. 매일 반복 전체는 예약 1개.
- 상태별 목록, 최근 내역 30개, 변경 버전 기반 기기 캐시.
- 데스크톱/세로/가로 화면, 동의 후 알림 설정 안내 숨김, iOS 홈 화면 설치 가이드.
- 초기 시작 화면과 오류/지연 재시도, 스크립트/worker 버전 갱신, 카카오톡 외부 브라우저 안내.

Flutter analyze, Flutter 18개·JS/backend 33개·Rules/통합 15개 검사와 production build를 통과했습니다. 신규 root 캐시 갱신·구형 진입 HTML 복구를 검사했습니다. 최신 초기화 수정 뒤 새 OS Push 수신을 다시 시험한 것은 아닙니다.

서버는 매분 예약을 처리하며 정각·무누락 전달은 보장하지 않습니다. 개인정보 문의/삭제 절차와 자동 보관 정책은 아직 확정 전입니다. [사용법](USAGE.md) · [구조](ARCHITECTURE.md) · [데이터 처리의 현재 범위](DATA-AND-PRIVACY.md) · [이미지 출처](README-MEDIA.md)
