# 디시 스크롤 도우미 1.5.0 구조

Manifest V3 콘텐츠 스크립트와 로컬 설정 저장용 서비스 워커로 이루어진 확장입니다. 서버나 런타임 외부 의존성은 없습니다. `extension/`을 그대로 Chrome에 로드할 수 있습니다.

| 파일 | 책임 |
|---|---|
| page-context.js | hostname·pathname·query와 DOM으로 페이지 및 갤러리 종류 판별, 대상 요소와 본인 갤로그 주소 확인 |
| navigation.js | 현재 목적지로 짧게 이동한 뒤 다시 위치 확인, 문서 높이·레이아웃 변화 추적, 안정화 및 취소 |
| shortcuts.js | 기본 키·키 조합 정규화·중복 검사, 입력 포커스 보호와 실행 가능 동작 판별 |
| settings.js | 설정 정규화, 슬롯·배치·아이콘 모델, 최근 갤러리 최대 두 곳 처리 |
| background.js | 여러 탭에서 발생하는 설정·방문 기록 쓰기를 순서대로 처리 |
| ui.js / style.css | Shadow DOM 패널·설정창, 버튼·줄 구분선·커스텀 슬롯 조작 |
| content_script.js | 페이지 변화, 설정 저장과 UI·이동 작업의 생명주기 연결 |
| icons/ | 패키지에 포함된 대표 아이콘과 CSS mask용 이미지 |

댓글·댓글쓰기·글 목록은 현재 DOM 위치를 다시 찾는 같은 이동 기반을 사용합니다. 맨 아래는 실제 스크롤 요소의 바닥과 높이 안정화를 확인합니다. 새 명령, Esc 및 직접 스크롤은 앞선 이동을 취소합니다.

클릭과 단축키는 동일한 동작 실행 경로를 사용합니다. 설정 schema 4는 버튼별 키 조합과 명시적인 해제를 저장하며 기존 모양·배치·갤러리는 보존합니다. 입력 이벤트는 현재 키 동작 판단에만 사용하고 입력 내용을 기록하거나 전송하지 않습니다.

설정은 `chrome.storage.local`의 `dcScrollSettings`, 최근 갤러리는 `dcScrollRecentGalleries`에 저장됩니다. 갤러리 기록에는 종류·ID·글 목록 URL만 최대 두 곳을 유지합니다. 게시글 번호와 열람 시각은 저장하지 않습니다. 방문 기록 지우기와 설정 기본값 복원은 별도 동작입니다.

`storage` 외의 별도 권한은 없습니다. 지정된 DCInside 주소에서만 콘텐츠 스크립트가 실행됩니다. 확장이 원격 코드를 다운로드하거나 사용자 정보를 개발자 서버에 전송하는 경로는 없습니다.

이 문서는 출시 소스의 구조를 설명합니다. 자동 테스트와 개발용 재현 페이지는 비공개 개발 저장소에서 관리하며 이 실행 소스 스냅샷에는 포함하지 않습니다.
