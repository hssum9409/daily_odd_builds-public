# 이미지 출처와 라이선스 범위

대표 로고, 툴바·커스텀 아이콘과 홍보 일러스트는 2026년 10월 이 프로젝트를 위해 OpenAI Image Gen으로 생성했습니다. 크기별 PNG는 생성 원본을 내보낸 파일입니다. 파란색 `dc`와 스크롤 기호는 독립적인 도우미 확장의 로고이며 DCInside 공식 로고나 인증 표시가 아닙니다.

| 공개 파일 | 용도 |
|---|---|
| assets/logo.png | README 대표 로고 |
| extension/icons/*.png | 확장 대표 아이콘과 버튼 이미지 |
| docs/images/feature-poster1280x800.png | 주요 기능 홍보 일러스트 |
| docs/images/promo440x280.png | 작은 프로모션 타일 |
| docs/images/marquee1400x560.png | 마키 프로모션 타일 |

홍보 이미지의 페이지와 패널은 설명용 일러스트입니다. 실제 DCInside 화면 캡처나 사용자 수·평점·공식 승인을 나타내지 않습니다. 실제 사용 스크린샷은 Chrome 웹 스토어 등록정보에서 별도로 제공합니다.

`LICENSE`의 MIT는 실행 코드와 문서에 적용됩니다. 프로젝트가 제공하는 생성 로고·아이콘·홍보 이미지는 이 프로그램의 배포·소개에 함께 사용할 수 있습니다. 이 안내는 제3자 상표나 다른 사이트의 콘텐츠에 대한 권리를 부여하지 않습니다. 생성 이미지는 다른 결과물과 유사할 수 있으며 독점성을 보장하지 않습니다.

Day 001의 캐릭터 아트나 다른 사이트의 원본 이미지를 이 폴더에 복사하지 않았습니다.

## 2026-10-27 · 기능별 이미지와 실제 UI 예시

생성 일러스트는 GPT-6 Astra / High 아트 작업자가 Day 1·2·3·7·8의 실제 참고 이미지와 이 확장의 소스를 확인하고 내장 이미지 생성 도구를 직접 호출해 만들었습니다. 이미지 backend 모델·품질·과금 등급은 도구에 노출되지 않았습니다. 생성 그림의 버튼·기기는 설명용이며 실제 화면과 구분합니다.

UI 캡처는 2026-10-27 Windows Chromium의 1265×711 화면입니다. UI 파일은 공개 1.5.0 소스 그대로이며, URL 문맥과 저장소 API는 로컬 재현 장치로 제공합니다. 실제 DCInside 운영 페이지, Chrome 확장 설치·스토어 배포 또는 실물 모바일 검증이 아닙니다. 테스트 페이지에는 개인 계정·글·댓글·방문 기록을 넣지 않았습니다. 생성 PNG와 캡처 원본을 보존하고 공개 WebP는 같은 크기의 무손실 변환으로 제공합니다.
