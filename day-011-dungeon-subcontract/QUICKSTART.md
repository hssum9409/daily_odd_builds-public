# 처음 시작하기

1. [게임](https://daily-odd-builds-dungeon.web.app/)에서 **새 사업 시작**을 누르고 안내를 읽습니다. 7×11 던전과 1,200G로 시작합니다.
2. **직원**에서 코볼트 100G와 오크 220G를 채용합니다. 직원 카드의 **배치 / 이동**을 누른 뒤 중앙 몬스터 방의 대기석에 배치합니다. 방을 선택하면 좌표와 자리가 보입니다.
3. **계약**에서 슬라임 동네 반장의 의뢰를 수주합니다. 안내대로 왼쪽 입구와 오른쪽 출구 차원문을 지정합니다. 지도 클릭 대신 차원문 목록에서도 고를 수 있습니다.
4. 시간은 자동으로 흐릅니다. **하루 빠르게**로 다음 날을 진행할 수도 있습니다. 현장 화면에서 전투를 보고, 연출 배속·생략을 선택합니다. 연출을 멈춰도 날짜는 흐릅니다.
5. 부상·피로·사기를 살피고 필요한 직원 요청을 지급합니다. 주간 전표에서 급여와 순손익을 확인합니다. 무리한 계약은 위약금을 부를 수 있습니다.
6. **던전 → 던전 배치 시작**으로 초안을 엽니다. 통로를 이어 그리고, 종류와 크기를 고른 방을 놓고 회전합니다. 초록 ↔는 입구까지 연결, 주황 ○는 입구 단절, 빨강 ×는 통로 없음·방향 불일치입니다.
7. 보조 기능은 **더보기**, 들어낸 방은 **보관 N**, 저장 실패 목록은 **확인 N**에서 엽니다. **배치 저장**만 실제 구조와 비용을 확정합니다. **변경 취소 → 변경 버리기**는 초안만 버립니다.
8. 증축은 가로·세로 한 칸씩 투자합니다. 공간과 차원문 등급이 준비되면 여러 계약을 운영할 수 있습니다. 계약은 던전과 몬스터·시설을 공유합니다.

모바일은 **구획 선택**에서 목록을 열고 **닫기 · 지도 편집**으로 돌아옵니다. **지도 이동**에서는 한 손가락 드래그로 지도를 옮기고, **선택 / 배치**에서 클릭·터치로 배치합니다. **전체 보기 → 미니맵 → 선택 위치 / 편집 배율**을 사용해 큰 던전을 확인합니다.

## 저장과 기기 이동

기기 자동저장이 기본입니다. 별도로 **설정 → 저장 코드 만들기 → 저장 코드 복사**로 코드를 보관합니다. 다른 기기·브라우저·사이트 주소에서는 **설정 → 저장 코드 불러오기 → 코드로 복원**을 사용하세요. JSON 파일 내보내기/불러오기도 제공합니다. 미저장 초안은 옮겨지지 않습니다.

기존 로컬 주소와 공개 HTTPS 주소는 서로 다른 저장 공간을 사용합니다. 로컬 진행을 이어가려면 주소를 바꾸기 전에 코드를 내보내세요.

## ZIP으로 실행

제품 전용 [0.13.0 릴리스](https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day011-dungeon-v0.13.0)에서 ZIP과 SHA-256 파일을 받습니다. ZIP을 풀고 해당 폴더에서 다음과 같이 HTTP 서버로 실행할 수 있습니다.

```sh
python -m http.server 8080
```

`http://127.0.0.1:8080/`을 엽니다. `index.html`을 파일로 직접 열지 마세요. ZIP의 `RUNME.txt`와 라이선스 고지도 함께 보관합니다. 사이트 배포·되돌리기는 [배포 방법](docs/DEPLOY.md)을 참고하세요.
