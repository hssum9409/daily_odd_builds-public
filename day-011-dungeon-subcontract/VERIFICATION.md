# 0.13.0 MVP 검증

포털 Day 011 기록일은 2026-10-22, 실제 공개일은 2026-10-23입니다. 공개 배포물은 원본 소스 공개가 아닌 정적 웹 릴리스입니다.

- TypeScript와 Vite production build 성공.
- 렌더링 없이 실행되는 Vitest 19파일 / 158개 통과. 경로·차원문·복수 계약·파악도·직원·시설·경제·저장·확장 규칙 포함.
- 편집 UI 버전의 브라우저 회귀 49개 통과. 정상 새 게임부터 16주 자동 플레이, 유료 증축·복수 계약과 실제 오프라인 복귀 포함.
- Day 011 명칭·PWA 메타데이터 반영 후 실제 플레이, 모바일 편집, 차원문 지정, 카메라, 아이콘·스플래시와 네트워크 없는 재열기 8개 재검증 통과.
- 공개 ZIP의 CRC 검사와 모든 정적 파일 바이트 비교 통과. 정확한 배포 해시는 metadata.json / SHA256SUMS.txt에 기록.
- 새 홍보 일러스트 3종과 실제 UI 캡처를 구분. WebP와 아이콘의 실제 디코딩 확인.

검증 환경은 Windows Chromium입니다. 전용 Browser plugin이 제공되지 않아 기존 Playwright를 사용했습니다. PC 화면과 390×844 / 360×640 화면·터치 에뮬레이션을 검사했습니다. 에뮬레이션은 실물 iOS/Android·홈 화면 설치·Safari/Firefox 검증을 대신하지 않습니다. 모든 고급 계약 조합의 장기 난이도를 확인한 것은 아닙니다.

공개 HTTPS `https://daily-odd-builds-dungeon.web.app/`에서도 위 핵심 8개 시나리오가 모두 통과했습니다. 새 게임·직원 배치·실제 전투·정산·저장 복구, 차원문 지정, 모바일 편집, 아이콘과 네트워크 없는 재열기를 확인했습니다. 공개 서버의 459개 파일이 배포 ZIP과 SHA-256 기준으로 일치합니다. 서버·로그인·멀티플레이를 제공하는 제품으로 표시하지 않습니다.
