# 만든 데 쓴 토큰

토큰 쓴 걸 자랑하는 사이트를 만들겠다고, 만드는 데도 **276,674,216토큰**을 썼습니다. 수집할 숫자를 늘려버리는 개발... 이거 맞나.

집계 시점은 **2026-10-22 07:46 KST**입니다. 해당 시점까지 로컬 로그로 확인한 프로젝트 제작 누적값이며, 이후 문서 수정·배포·검증 작업은 포함하지 않습니다. 사이트에 제출한 계정의 평생 사용량이나 순위 점수와 다른 수치입니다.

| 항목 | 토큰 |
| --- | ---: |
| **기록된 누적 합계** | **276,674,216** |
| 입력 | 275,328,836 |
| 입력 중 캐시 사용분 | 268,566,272 |
| 출력 | 1,345,380 |
| 출력 중 reasoning | 600,448 |

주 작업 세션 1개의 **269,104,866**과 소개·아트디렉션 보조 세션 1개의 **7,569,350**을 합산했습니다. 확인 가능한 고유 세션은 총 2개입니다. 재개 전·후 파일에 같은 주 작업의 누적값이 있어도 마지막 누적값 한 번만 사용했습니다.

## 계산은 이렇게 했습니다

- Codex 세션 로그의 `token_count` 이벤트에서 고유 세션별 마지막 누적 `total_token_usage`를 사용합니다. 압축된 이전 로그와 재개된 로그도 확인해 같은 세션을 중복 합산하지 않았습니다.
- 합계는 입력 + 출력입니다. 캐시 입력은 입력에, reasoning은 출력에 이미 포함되어 있어 다시 더하지 않습니다.
- 여러 차례 같은 문맥을 읽은 사용량을 포함합니다. 새로 만든 글자 수·현재 문맥 크기·결제액·생산성이나 개발 실력을 뜻하지 않습니다.
- 내장 이미지 생성 도구의 사용량을 텍스트 토큰으로 환산하지 않습니다. 확인되지 않는 세션의 사용량도 추정해 더하지 않습니다.
- 공개 포털 Day 008의 토큰 필드와 이 문서·JSON은 같은 시점의 같은 수치를 사용합니다. 원본 로그·대화·세션 식별자·계정 정보·로컬 경로는 공개하지 않습니다.
