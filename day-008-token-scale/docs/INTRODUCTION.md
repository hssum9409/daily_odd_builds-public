# Day 008 · 마 니 토큰 좀 쓰나?

> Token Scale Is All You Need · 0.4.0 소개 원고

## 한 줄 소개

**토큰은 썼고, 자랑할 곳은 필요하니까.** Codex 토큰 통계를 닉네임 랭킹과 업적 도감으로 구경하는 비공식 커뮤니티.

## 공개 소개문

Codex를 쓰다 보면 문득 궁금해집니다. 나는 얼마나 썼고, 다른 사람들은 얼마나 쓰고 있을까?

**마 니 토큰 좀 쓰나?**는 그 궁금증에서 출발한 작은 커뮤니티입니다. 컴퓨터에서 실행하는 수집기가 로컬 Codex의 계정 통계를 읽고, 웹에서 내 기록과 업적을 보여줍니다. 공개 랭킹에 참여하면 다른 사람들과 숫자를 비교할 수도 있습니다. 많이 썼다는 사실이 일을 잘했다는 뜻은 아니지만, 배지 하나쯤 붙여놓기엔 충분히 재미있잖아요.

프로필에는 닉네임을 달고, 모양·표정·장식·색상을 조합해 아바타를 만듭니다. 짧은 소개와 GitHub 링크도 붙일 수 있습니다. GitHub 링크는 직접 입력하는 주소이며 계정 인증 기능은 아닙니다. 공개 프로필에는 대표 배지를 최대 다섯 개 보여줍니다.

업적 도감은 343개 규칙으로 구성됩니다. 지금 판정기가 지원하는 것은 226개이며, 나머지 117개는 필요한 데이터가 준비될 때까지 대기합니다. 누적 토큰, 관측된 연속 사용, 최장 단일 턴 등 제공된 지표로만 조건을 확인합니다. 받아오지 못한 값에 임의의 숫자를 채우지 않습니다.

수집기는 큰 창을 차지하지 않습니다. Windows에서는 트레이, Mac에서는 메뉴 막대에서 상태를 확인합니다. 처음 웹에 연결한 뒤 30초마다 로컬 통계를 읽고, 마지막 저장값에서 달라진 부분만 보냅니다. 내 통계와 공개 순위의 속도는 다릅니다. 공개 랭킹은 6시간마다 묶어서 집계합니다.

공개 참가와 통계 수집은 별도 선택입니다. 개인 기록만 확인해도 됩니다. Google 로그인은 서비스 계정에, Codex 로그인은 원본 통계 조회에 쓰입니다. OpenAI 인증 토큰·대화·코드·프로젝트 경로는 서비스 서버로 보내지 않습니다.

이 기록은 `community_reported`입니다. 제출된 수치에 원본 API의 서명이 없으므로 위조 방지나 공식 인증을 보증하지 않습니다. OpenAI가 제작하거나 승인한 서비스도 아닙니다. 그냥, 토큰 좀 썼다는 사람들끼리 구경하는 곳입니다.

Windows는 실제 설치와 Codex 조회·웹 연결·서버 저장을 확인했습니다. **macOS는 실기기 미검증 preview**입니다. 한국어·영어·일본어·중국어 간체를 지원합니다.

## 짧은 배포문

**Day 008 — 마 니 토큰 좀 쓰나?**

Codex 계정의 토큰 통계를 닉네임 랭킹과 업적 도감으로 보는 작은 커뮤니티를 만들었습니다. 아바타를 꾸미고, 배지를 고르고, 공개 여부는 직접 정합니다.

0.4.0 수집기는 로컬 통계를 30초마다 조회하고 바뀐 값만 전송합니다. 공개 랭킹은 6시간마다 갱신합니다. OpenAI 인증정보나 대화 내용은 보내지 않습니다.

공식 인증이나 생산성 평가가 아닌 재미용 `community_reported` 랭킹입니다. Windows 실제 실행 확인, macOS 실기기 미검증 preview.
