# 공개 범위와 OpenAI 정책 검토

검토일·서비스 공개일: 2026-10-21. 사용자 지시에 따라 0.3.1을 정식 배포하고 웹 서비스를 공개합니다.
이 결정은 운영자의 공개 결정이며 OpenAI의 승인·법적 허가·통계 진위 인증을 의미하지 않습니다.

## 공식 문구와 현재 구조

[App Server 공식 문서](https://learn.chatgpt.com/docs/app-server#auth-endpoints)는 기존 로컬·오픈소스 앱의
App Server 인증 사용을 계속 허용하고, commercial/hosted service에서 App Server 인증을 쓰는 것은
허용하지 않는다고 설명합니다. 그러나 사용자가 로컬에서 읽은 집계 통계만 별도 서비스에 제출하는
구조를 구체적으로 허용하거나 금지하는 설명은 찾지 못했습니다.

이 서비스에서 OpenAI 인증은 사용자의 로컬 Codex가 관리합니다. 수집기는 로컬 stdio의 읽기 전용
메서드로 통계만 읽고, 웹·서버는 별도 Google/Firebase 인증으로 최소 통계를 받습니다. 서버는
OpenAI 계정 인증·OAuth 토큰 보관·OpenAI API 호출·ChatGPT 플랜을 이용한 모델 실행을 하지 않습니다.
따라서 랭킹 웹이 호스팅된다는 이유만으로 해당 제한 위반이라고 단정하지 않습니다. 다만 이 조합에
대한 OpenAI의 명시적인 승인이나 예외를 확인했다는 주장도 하지 않습니다.

[Sign in with ChatGPT 플랜 사용 문서](https://developers.openai.com/siwc/token-sharing-open-source)는
사용자의 ChatGPT 플랜으로 Responses API 요청을 실행하는 기능을 설명합니다. 현재 통계 수신
구조에 그 전환이 필수라고 판단할 근거는 확인되지 않았습니다.
[일반 이용약관](https://openai.com/policies/terms-of-use/)에는 자동 데이터 추출 제한이 있으나,
문서화된 통계 조회와 제3자 통계 제출에 대한 적용 범위는 명시되어 있지 않습니다.

종전의 ‘정책 위반 또는 공개 불가가 확인됨’처럼 읽히는 안내를 정정했습니다. 향후 공식 안내가
현재 용도를 제한하면 해당 경로를 중지·수정합니다. 인증 우회나 사용자 모르게 하는 로그인은 없습니다.
사용자 지시 없이 OpenAI에 메시지를 보내지 않습니다.

## 수집·인증 정보 분리

OpenAI OAuth credential/auth.json/API Secret을 읽어 복사하거나 Firebase에 보관하지 않습니다.
Collector는 자신의 자식 App Server 프로세스의 허용된 메서드만 호출합니다. 대화, 프롬프트,
코드, 작업 경로는 통계 payload에 없습니다. 계정 이메일로 만든 로컬 식별 hash도 전송하지 않습니다.

Google 로그인에는 Firebase Authentication이 제공하는 일반 이메일/프로필 식별정보가
서비스 인증 시스템에 처리됩니다. 공개 랭킹/Firestore 통계 문서에는 이 정보를 쓰지 않습니다.
‘통계에 이메일을 보내지 않음’과 ‘Google 로그인에서 이메일을 전혀 처리하지 않음’은 다릅니다.
OpenAI 인증과 Firebase 인증을 혼동하지 않습니다.

공개 닉네임은 1~20자로, CJK/공백을 지원하고 동일 닉네임을 허용합니다. UID가 실제 연결
기준입니다. 마크업/제어문자를 클라이언트에서 거절하고 HTML로 렌더하지 않습니다. 서버도
길이/마크업을 검사합니다. 비속어·사칭 자동 판정 목록은 아직 없으며 신고/관리자 차단 경로가 있습니다.

공개/전송 동의는 각각 OFF가 기본입니다. 비공개 전환은 서버 lease로 랭킹 발표와
직렬화하고 공개 문서와 캐시 세대를 제거합니다. 두 DB 사이 공통 트랜잭션은 없으며
중단된 제거는 서버에서 재시도합니다. 이미 받은 화면/외부 캡처까지 회수할 수 있는 것은 아닙니다.
웹에서 서비스 계정과 통계를 삭제할 수 있습니다. 사용자 본인의 실제 계정 삭제 테스트는
실행하지 않습니다. 삭제/권한 경로는 에뮬레이터에서 검증합니다.

소스와 운영 데이터는 분리합니다. `.research`, `.local`, 캐시/세션, 실제 화면 증거는 Git에서
제외합니다. 공개 저장소에는 승인된 코드 스냅샷만 포함합니다. 개인 키, OAuth 세션, 실제
사용자 통계를 배포하지 않습니다. 운영 연락처·보존/삭제·이용 안내는 웹의 [/about/](https://token-arena-hssum9409.web.app/about/)에서 제공합니다.
정식 인증서 구매나 OS 보호 해제 없이 배포하며, 서명·공증과 대상 기기의 미검증 범위를 설치 안내에 표시합니다.

ChatGPT 로그인은 계정 소유권 확인과 클라이언트 통계의 진위 확인을 분리해 검토합니다.
현재 통계는 로그인 상태와 관계없이 `community_reported`입니다. 새 정식 로그인 제공
범위와 중복 계정 연결의 개선 가능성은 [공개 인증 구조 안내](https://token-arena-hssum9409.web.app/about/?lang=ko#authentication)에
기록했습니다. OpenAI 인증정보를 Firebase에 저장하는 구조는 추가하지 않았습니다.
