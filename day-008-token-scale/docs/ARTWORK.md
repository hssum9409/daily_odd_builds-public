# Day 008 홍보 아트

## 제작 상태

2026-10-22: GPT-6 Astra / High가 소개 문안·아트 디렉션·프롬프트를 작성했고, 부모 세션에서 내장 imagegen을 실행했습니다. 생성 PNG와 무손실 WebP를 1672×941로 저장하고 제목·예시 수치·연출 주석 및 RGBA 픽셀 일치를 확인했습니다. 실제 생성 프롬프트는 [hero-prompt.txt](hero-prompt.txt), 파일 검증은 [README-MEDIA.md](README-MEDIA.md)에 보존합니다.

## 방향

**작은 토큰 동호회의 트로피 진열장.** 숫자를 두고 장난치는 제목은 크게, 제품은 정돈된 흰색·초록색 카드로 보여줍니다. 랭킹 표, 프로필 아바타, 업적 배지를 하나의 입체 정물처럼 배치합니다. 고급스러운 제품 사진의 여백과 가벼운 장난감을 닮은 재질을 함께 사용합니다.

가로 비율 16:9, 1600×900 안팎을 목표로 합니다. 왼쪽 46%에 큰 한글 타이포그래피, 오른쪽 54%에 흰색 랭킹 카드와 작은 아바타·배지 오브젝트를 둡니다. 실제 웹은 평면 UI이며, 홍보 이미지의 두께·그림자·입체감은 설명용 연출입니다.

| 역할 | 색 | 근거 |
| --- | --- | --- |
| 주요 초록 | `#087F5B` | 실제 웹 `arenaGreen` |
| 본문/제목 | `#202323` | 실제 웹 `arenaInk` |
| 보조 글자 | `#596975` | 실제 웹 `arenaMuted` |
| 경계선 | `#E1E7E4` | 실제 웹 `arenaLine` |
| 카드 표면 | `#FFFFFF` | 실제 웹 기본 표면 |
| 옅은 민트 | `#E5F5EE` | 기본 아바타 배경 |
| 아바타/작은 강조 | `#FFB85C` | 기본 아바타 몸 색 |

배경은 흰색에서 옅은 민트로 흐르는 미세한 그라데이션으로 둡니다. Day 005의 크림색·식물·로봇을 반복하지 않습니다. 초록은 크고 분명한 제목과 기능 강조에, 주황은 작은 캐릭터와 배지에만 씁니다.

## 자산과 권리

클라이언트 코드의 MIT 라이선스와 생성 홍보 이미지의 제작 출처를 구분합니다. 이미지에는 내장 imagegen으로 새로 만든 홍보 연출과 이 프로젝트의 독자적인 UI·벡터 아바타 형태를 사용하도록 지시합니다. OpenAI 로고, 타사 캐릭터, 게임 아이콘·텍스처, 다른 Daily Odd Builds 제품의 캐릭터는 사용하지 않습니다.

폰트 파일을 내려받거나 재배포하는 작업은 이 제작 계획에 포함하지 않습니다. 생성 이미지 안의 글자는 이미지의 일부이며, 특정 상용 폰트 파일을 자산으로 제공하지 않습니다. 생성물의 독점권이나 제3자 권리의 완전한 부재를 보증하는 문구는 붙이지 않습니다.

생성 후 원본 PNG를 보존합니다. 크기 변경·형식 변환·텍스트 수정이 있었다면 실제 수행한 방식과 결과를 [README-MEDIA.md](README-MEDIA.md)에 기록합니다. 새 문구나 UI 수정은 내장 imagegen으로 작업하며, 생성 결과를 실제 제품 캡처로 표시하지 않습니다.

추가 네 장 모두 **예시 데이터 · 홍보용 연출**을 이미지 안에 표시합니다. 기능 카드의 배치·입체감·아이콘·색상 선택 UI는 실제 제품을 설명하기 위한 연출입니다. 실제 Flutter 렌더러 캡처가 아니며, 기능 동작이나 저장 성공을 입증하지 않습니다.

업적 이미지의 226개는 해당 예시 사용자의 달성 수가 아닌 **판정기 지원 규칙 수**입니다. 진행 카드의 `6M / 10M`, `60%`와 랭킹 이미지의 `128위`, `1.2M`은 가상 예시입니다. 프로필의 `계정 소유권 미확인` 문구는 GitHub 직접 입력 링크의 한계를 설명합니다. `비공개` 선택은 설정 예시이며 실제 계정 설정을 촬영한 것이 아닙니다.

정사각 카드에서 Hero의 작은 트로피가 유지되는 것은 장식입니다. 순위 우승 업적이 구현됐다는 표시로 해석하지 않습니다. 업적 기능 이미지는 개별 우승 업적을 제시하지 않습니다. 다른 게임이나 제품의 자산을 가져오지 않았습니다.

추가 PNG는 생성 도구가 반환한 원본을 그대로 복사했습니다. WebP는 Pillow의 lossless 형식 변환만 수행하며, 파일별 크기·SHA-256·RGBA 비교 결과는 [README-MEDIA.md](README-MEDIA.md)에 기록합니다.

### 가상 닉네임 편집

사용자가 예시 A/B/C 대신 장난스러운 닉네임을 요청해 정사각 카드·랭킹·프로필을 내장 imagegen으로 각각 편집했습니다. 최종 이름은 `알트만훔쳐보는얀르쿤`, `티보네이놈`, `82세박춘자인생최후의초기화권`이며 본인 순위는 `토큰은내가지갑은네가`입니다. 실제 이용자나 이름에 언급된 인물의 참여를 뜻하지 않는 가상 닉네임입니다. 토큰 수치와 프로필 내용도 예시입니다.

편집 전 이미지를 로컬 작업 보관 폴더에 남겼습니다. 구성·색·기능 설명·수치·예시 주석을 유지하도록 요청하고 결과를 직접 확인했습니다. 긴 닉네임은 두 줄 또는 작은 글자로 배치했습니다. 생성 편집이므로 닉네임 영역 밖의 픽셀까지 원본과 동일하다고 주장하지 않습니다.

실제 편집 프롬프트: [정사각 카드](prompts/social-card-nicknames.txt) · [랭킹](prompts/feature-rankings-nicknames.txt) · [프로필](prompts/feature-profile-nicknames.txt). 업적 이미지에는 닉네임이 없어 이번 편집을 적용하지 않았습니다. Hero의 별도 편집 기록은 해당 제작 담당자가 관리합니다.

## 브랜드 앱 아이콘

사용자의 favicon·설치 앱·스플래시 브랜딩 요청으로 **`docs/images/brand-icon.png`**를 추가 제작했습니다. Hero와 정사각 카드를 직접 보고 내장 imagegen의 참고 이미지로 전달했습니다. 정확한 프롬프트는 [brand-icon.txt](prompts/brand-icon.txt)입니다.

오렌지 불꽃·초록 왕관·검정 눈과 미소를 단순화하고, 연한 민트색 배경이 정사각형 전체를 채우도록 했습니다. 텍스트·테두리·장치 목업·내부 라운드 사각 프레임을 넣지 않았습니다. 둥근 모서리는 운영체제의 아이콘 마스크에 맡깁니다.

원본은 1254×1254 PNG이며 전 픽셀의 알파가 255입니다. 색상 주체를 채도 기준으로 추린 근사 검사에서 중심으로부터 최대 반경은 캔버스 폭의 약 0.371로, 반경 0.4의 중앙 안전원 안에 들어갑니다. 이는 이미지의 여백 검사이며 실제 PWA 설치나 모든 OS 마스크·16px 가독성 검증을 대신하지 않습니다.

아이콘 원본 생성과 favicon/manifest/스플래시 적용은 별도 작업입니다. 파생 아이콘 크기·ICO 생성·웹 배포·실제 브라우저 확인은 웹 반영 담당자의 검증 기록을 따릅니다. 이 아트 작업에서는 웹 코드를 변경하지 않았습니다.
