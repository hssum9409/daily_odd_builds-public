Day 001의 대표 이미지와 접힌 상세 안내, Day 002의 큰 한글 제목과 실제 화면/연출 구분, Day 003의 기능 중심 포스터, Day 005의 차분한 재질과 입체적 제품 연출을 참고했습니다. Day 005 Hero를 직접 열어 구도를 확인했습니다. 다른 프로젝트의 캐릭터·UI·로고를 가져오지 않습니다.

색과 아바타 형태의 근거는 이 프로젝트의 `packages/token_arena_ui/lib/token_arena_ui.dart`, `avatar.dart`, `packages/token_arena_core/lib/src/profile.dart`입니다. 화이트 바탕·초록 강조·짙은 회색 글자, 둥근 아바타와 불꽃 모양 등을 홍보물로 재해석합니다. 홍보 이미지의 재질·기울기·떠 있는 배지는 실제 UI 효과를 의미하지 않습니다.

예시에는 `예시 A`, `예시 B`, `예시 C`만 사용하고 실제 사용자명·이메일·UID·프로필·개인 통계·세션·로컬 경로를 넣지 않습니다. `12.8M`, `8.4M`, `3.2M`은 가상 수치입니다. 이미지 자체에 **수치 예시 · 홍보용 연출**을 표기합니다.

이 이미지로 Google 로그인, 실서버 저장, 순위 확정, 데스크톱 설치, macOS 실행이나 실제 업적 해금을 입증하지 않습니다. 기능 설명은 [공개 README 원고](../README.md), 검증은 [0.4.0 검증 기록](verification-0.4.0.md)을 기준으로 읽습니다.
