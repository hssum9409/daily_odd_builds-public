색과 아바타 형태의 근거는 이 프로젝트의 `packages/token_arena_ui/lib/token_arena_ui.dart`, `avatar.dart`, `packages/token_arena_core/lib/src/profile.dart`입니다. 화이트 바탕·초록 강조·짙은 회색 글자, 둥근 아바타와 불꽃 모양 등을 홍보물로 재해석합니다. 홍보 이미지의 재질·기울기·떠 있는 배지는 실제 UI 효과를 의미하지 않습니다.

Hero의 최종 닉네임은 `알트만훔쳐보는얀르쿤`, `티보네이놈`, `82세박춘자인생최후의초기화권`입니다. 사용자 요청에 따라 내장 imagegen으로 닉네임 영역을 편집했으며 실제 이용자나 언급된 인물의 참여를 뜻하지 않습니다. 실제 이메일·UID·프로필·개인 통계·세션·로컬 경로를 넣지 않습니다. `12.8M`, `8.4M`, `3.2M`은 가상 수치이며 **수치 예시 · 홍보용 연출**을 표기합니다. 편집 프롬프트는 [hero-nicknames.txt](prompts/hero-nicknames.txt), 최종 PNG SHA-256은 `51983f944e0c9d2bda58ef92f2408746b9cecef43598950cca0db08ca24d059e`입니다. WebP는 최종 PNG를 method 4 무손실 변환하고 RGBA 일치를 재확인했습니다.

이 이미지로 Google 로그인, 실서버 저장, 순위 확정, 데스크톱 설치, macOS 실행이나 실제 업적 해금을 입증하지 않습니다. 기능 설명은 [공개 README 원고](../README.md), 검증은 [0.4.0 검증 기록](verification-0.4.0.md)을 기준으로 읽습니다.
