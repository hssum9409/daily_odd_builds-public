# 성실삐 0.6.4 · Day 005

작은 위젯으로 업무·휴식을 기록하고, 같은 계정의 웹에서 구간을 수정하고 일간·주간·월간 통계를 확인합니다. Windows/Web beta와 macOS preview입니다.

- 웹: https://bbi.hssum.kr/
- 다운로드: https://bbi.hssum.kr/download
- 공개 릴리스: https://github.com/hssum9409/daily_odd_builds-public/releases/tag/day005-v0.6.4

## 달라진 점

- Windows 이메일·비밀번호 입력 영역의 포커스와 텍스트 표시를 수정했습니다. 마지막 로그인 성공 이메일과 로그인 세션을 기기의 암호화 저장소에서 복원합니다. 비밀번호 원문은 저장하지 않습니다.
- 업무/휴식 토글 오른쪽에 `퇴근` 글자 버튼을 제공합니다. 퇴근 후 `다시 시작하시나요? 얼마든지요!` / `업무 시작` 카드로 돌아오며, 오른쪽 빨간 X와 좌측 위 X는 위젯을 트레이/메뉴 막대로 숨깁니다.
- 좌측 위 `×` / `···`는 Day 1 HoverPill의 22px 크기·15px 글자·배치를 사용하고, 색만 크림·차콜 테마에 맞춥니다. 마우스를 올리면 나타나며 본체 불투명도와 분리해 표시합니다.
- 업무 시작에서 로그인한 뒤에도 설정창을 유지합니다. 설정 아이콘·프로그램 이름·앱 아이콘을 보완했습니다.
- 설치/앱 실행 때 시작 프로그램 등록을 묻습니다. 등록하거나 `다시는 묻지 않음`을 선택하면 다시 묻지 않습니다. `나중에`와 창 닫기는 다음 실행 때 다시 묻습니다.
- 웹은 사용자가 새로고침할 때 HTML을 재검증하고, 내용 해시가 붙은 새 JS/CSS를 받습니다. 버전 확인 폴링·자동 새로고침은 없으며 로그인 저장소를 지우지 않습니다.
- 대표 홍보물, 최신 Windows 기능 화면, 웹 예시 화면과 README를 공개 소스에 포함했습니다. 사용자가 제공한 로그인 인트로 이미지도 무손실 WebP로 제공합니다.

## 설치와 업데이트

ZIP 전체를 해제한 뒤 Windows는 `Install.cmd`, macOS는 `Install.command`를 실행합니다. 업데이트는 설정의 만든놈에서 확인하거나 새 ZIP의 설치 명령으로 진행합니다. Node, Flutter, .NET SDK와 Swift 개발 도구는 앱 실행에 필요하지 않습니다. `SHA256SUMS.txt`와 `release-manifest.json`을 제공합니다.

## 검증과 현재 한계

Windows PowerShell 5.1/WPF에서 크림·차콜·사용자 지정, 실제 번들 글꼴, 로그인 입력·이메일 기억·설정창 유지, 퇴근·재시작·트레이 숨기기, 시작 프로그램 동의 UI를 검사했습니다. 설치·업데이트·손상 패키지 거부·시작 실패 시 복구는 별도 임시 설치와 프로필에서 검증합니다. WPF 컨트롤 검사와 OS 포인터 입력은 구분합니다.

운영 Firebase 전용 임시 계정으로 로그인·구간 전환을 확인했습니다. 실제 Chrome PC/모바일 폭에서 새로고침과 새 탭 로그인 유지, 저장소 보존, 웹 캐시 헤더를 확인했습니다. 예시 화면은 사용자 데이터가 아닙니다.

macOS는 동일 구현과 네이티브 진단/검증기를 포함한 preview입니다. 구문·계산/정책 검사는 통과했지만 Mac 실기기의 AppKit 실행·설치·자동 실행·업데이트는 아직 검증하지 않았습니다. Windows 재부팅 후 자동 실행과 Android/iOS 배포도 이번 범위에 포함하지 않습니다.

개인정보처리방침 확정과 계정·전체 데이터 삭제 UI는 준비 중입니다. 기록 삭제는 복원 가능한 삭제입니다. Firestore 시점 복구는 활성화하지 않습니다.
