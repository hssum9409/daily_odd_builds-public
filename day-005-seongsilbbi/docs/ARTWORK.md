## 방향

성실삐의 크림·차콜 팔레트, 둥근 위젯 프레임, 둥근 한글/숫자 글꼴을 유지합니다. 귀여움은 곡선과 여백에서 표현합니다. 새 캐릭터·큰 로봇·반짝이·다른 앱의 아트는 추가하지 않습니다. 대표 카피는 **일한 시간을, 확실히 기록하세요.**입니다.

Day 001은 실제 UI를 전면에 두는 구성, Day 002는 가로/정사각 홍보물과 출처 구분, Day 003은 큰 한글 제목과 짧은 기능 설명을 참고했습니다. 그 이미지 자체를 합성하거나 재배포하지 않았습니다.

## 자산과 권리

- 로봇 원본은 Microsoft Fluent Emoji의 Robot 아트입니다. 패키지의 [MIT 고지](../desktop/assets/LICENSE-Fluent-Emoji.txt)를 유지합니다.
- Windows 캡처는 제품에 포함한 Nunito·나눔스퀘어라운드를 사용합니다. [Nunito OFL](../desktop/assets/OFL-Nunito.txt), [나눔스퀘어라운드 OFL](../desktop/assets/OFL-NanumSquareRound.txt).
- 웹 캡처는 제품 CSS와 동일한 글꼴 구성을 사용합니다.
- 생성 이미지를 앱 아이콘이나 UI 자산의 대체 원본으로 쓰지 않습니다. 기존 브랜드와 실제 앱 디자인을 유지합니다.


## 사용자 제공 로그인 인트로

`docs/images/login-intro.webp`는 사용자가 제공한 성실삐 로그인 인트로 PNG를 크기·색·문구 변경 없이 무손실 WebP로 변환한 파일입니다. 865×777이며 디코딩한 RGBA 픽셀 일치를 확인했습니다. 기존 대표 홍보 이미지를 대체하지 않고 별도 이미지로 제공합니다.
