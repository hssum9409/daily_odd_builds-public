## 사용하기

웹에서 이메일로 가입하고 성실삐 인증 메일을 확인합니다. 데스크톱에서도 같은 계정으로 로그인하면 기록을 이어갑니다. 위젯은 업무 중 누적 업무시간, 휴식 중 업무/이번 휴식시간을 표시합니다. 시작·일시정지는 버튼 하나로 조작하고 퇴근·대시보드·설정은 메뉴에서 엽니다. 웹에서 구간 이름·시작·종료 시각을 수정하거나 삭제·복원하고 일간·주간·월간 통계를 확인합니다.

Windows는 ZIP 전체를 압축 해제한 후 `Install.cmd`, macOS는 `Install.command`를 실행합니다. 별도의 Node, Flutter, .NET SDK 또는 Swift 개발 도구 설치가 필요 없습니다. 설치형이므로 설치 후 다운로드 폴더는 지워도 됩니다. 자세한 명령과 경로는 [데스크톱 안내](desktop/README.md)를 참고하세요.

## 업데이트

Day 1의 GitHub 릴리스 업데이트를 성실삐의 `day005-v` 채널에 적용했습니다. OS별 ZIP·버전·다운로드 주소·크기·SHA-256을 확인한 뒤 기존 설치기를 통해 교체하고 실행을 확인합니다. 실패하면 이전 버전 복구를 시도합니다. 계정·업무 기록과 디자인 설정은 설치 폴더 밖에 유지합니다.

만든놈 탭에서 수동 확인 또는 자동 설치를 선택합니다. 자동 설치는 기본 꺼짐이며 새 버전이 발견되면 설치 여부를 확인합니다. 기본 조회 간격은 6시간입니다. GitHub에 업무 기록·Firebase 자격증명을 보내지 않습니다. 체크섬은 게시자 전자서명이 아닙니다. 업데이트용 ZIP은 앱이 사용하는 파일이며 직접 실행용이 아닙니다.

## 배포 범위와 한계

- 웹·Windows는 **beta**, macOS는 **preview**입니다. Android/iOS 배포는 포함하지 않습니다.
- Windows의 실제 PowerShell 5.1/WPF 설치·실행·테마·업데이트·제거와 손상 패키지 거부, 실행 실패 시 복구를 검사했습니다. UI 검사는 프로그램식 WPF 이벤트를 포함하며 새 PC의 보안 정책·실제 마우스·다중 모니터 검증과 구분합니다.
- **실제 Mac 실행은 미검증**입니다. AppKit·Keychain·다운로드 ZIP 설치·업데이트·Gatekeeper·Spaces·전체 화면 확인이 필요합니다. `Diagnose.command` 검증기를 포함했습니다.
- 개인정보처리방침 확정과 계정·전체 데이터 삭제 UI는 아직 남아 있습니다. 기록 삭제는 복원 가능한 소프트 삭제이며 앱 제거가 계정 삭제를 의미하지 않습니다.
- 쓰기는 온라인 연결이 필요하며 완전한 오프라인 편집·병합은 지원하지 않습니다. 그룹·랭킹도 포함하지 않습니다.

이 디렉터리는 공개 배포에 필요한 데스크톱 스크립트·설정·자산·패키징 도구의 릴리스 스냅샷입니다. 운영 서버와 개발 저장소의 이력·자격증명·사용자 데이터는 포함하지 않습니다. 개발 소스의 기존 `WorklogScripts` 식별자와 Firebase 프로젝트는 계정·설정을 이어 쓰기 위해 유지합니다.
