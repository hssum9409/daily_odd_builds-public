# 지피쨩 앱 아트 — v0.7.1

사용자가 제공한 `1790708611.png` 기본형 마스터 시트를 기준으로 제작했다. 은백색 짧은 머리, 파란 눈, 삼각형 머리핀, 흰 테크 재킷과 검은 GPT 이너를 유지한다. 원래 ChatGPT Pet 이미지는 변경하지 않는다.

## 제작 방식

Codex 내장 imagegen의 이미지 편집 모드로 참조 시트와 연결된 아트를 생성했다. 각 호출은 `transparent_background=true`를 사용했다. 얼굴 PNG는 아이콘, 태블릿을 든 상반신 PNG는 설정창에 적용한다. 후속 편집은 설정 아트의 바깥 배경을 투명하게 정리했다.

- `codex_usage_monitor/assets/gp-chan-face.png`: 얼굴 중심 아이콘 원본.
- `codex_usage_monitor/assets/gp-chan-monitor.png`: 사용량 태블릿을 든 설정창 아트.
- 빌드 시 얼굴 원본을 16/20/24/32/40/48/64/128/256px ICO로 변환한다. 이 변환과 표시 크기 리샘플링 외에는 코드로 이미지를 편집하지 않았다.
- 두 PNG는 EXE 내부에 포함된다. 설정창의 버튼과 스위치는 실제 위젯이며 캐릭터 부분만 이미지다. 대기 트레이는 EXE 아이콘 리소스를 사용하여 Pillow나 Tk를 로드하지 않는다.

## 생성 프롬프트 요약

**얼굴**: 제공된 캐릭터시트의 지피쨩과 동일한 인물로, 작은 Windows 앱·트레이 아이콘에서도 읽히는 얼굴 중심 일러스트. 은백색 단발, 파란 눈, 남색·파란 삼각 머리핀, 부드러운 미소. 얼굴과 머리카락을 캔버스의 약 88% 안에 크게 배치하고 잘리지 않는 여백 유지. 검은 GPT 칼라와 흰 재킷은 최소한으로 포함. 투명 배경, 테두리·배지·고양이·설명 문구 없음.

**설정창**: 같은 얼굴·의상·인물성을 유지한 허리 위 초상. 양손으로 작고 얇은 사용량 태블릿을 들고, 태블릿에 파란색·민트색 사용량 막대와 작은 원형 게이지 표시. 흰 테크 후드 재킷과 검은 GPT 이너를 유지. 차분한 데스크톱 사용량 도우미 컨셉, 세로 구성, 투명 배경. 추가 장식이나 설명 문구 없음.

**투명 배경 정리**: 완성된 포즈·얼굴·머리카락·태블릿·의상을 보존하고 인물 밖 회색 배경만 제거. 실루엣 밖 알파는 0, 불필요한 회색 후광 없이 자연스러운 가장자리 유지.

## 스크립트 에디션 0.2.0

위 원본 앱의 두 PNG를 변경 없이 `assets/`에 동봉했다. 얼굴 ICO만 같은 크기 목록으로 변환했다. 두 스크립트 플랫폼 모두 이 에셋을 읽으며 코드 UI와 별개다. 이 기록은 기존 아트의 출처 기록이며 사용자 제공 캐릭터의 권리를 새로 허가하는 문서는 아니다. 코드의 MIT LICENSE와 함께 보존한다.

## 공개 스크립트 배포의 적용 범위

배포 ZIP의 `assets/gp-chan-face.png`, `assets/gp-chan-monitor.png`, `assets/gp-chan.ico`를 두 OS에서 함께 사용합니다. 코드의 MIT 라이선스는 캐릭터 원본에 새로운 권리를 부여하지 않습니다. 사용자 제공 시트를 참조한 아트이며 OpenAI의 공식 제품 아트로 표시하지 않습니다.
