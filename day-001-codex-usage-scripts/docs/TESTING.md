# 공개 버전 검증 범위

Windows 격리 설치·자동 시작 실행기·업데이트·롤백·복구 실패 로그·제거를 실제 PowerShell 5.1로 검사했습니다.
수정하지 않은 공개 1.4.4 업데이터를 설치 폴더 안에서 실행해 새 후보로의 설치형/포터블 갱신과 재실행을 검사했습니다.
Pet 실조작·Windows 로그온·실제 Codex 종료는 이번 유지보수 범위에서 재검사하지 않았습니다.
배포 ZIP을 압축 해제한 실제 WPF 설정창, 알림 프로세스 재시작과 구버전 기록 복원, 작업표시줄 Shell 속성/바로가기 실행도 검사했습니다.
작업표시줄 아이콘은 실제 HWND의 등록 속성으로 확인했으며 Explorer 픽셀을 캡처한 육안 검사와는 구분합니다.

GitHub HTTP/확인창 응답은 로컬 fixture로 대체했으며 공개 후 실제 다운로드 검증을 별도로 수행합니다.
Mac은 preview입니다. v6까지의 사용자 실기기 진단에서 글자 표시·CLI 발견·사용량 응답을 확인했습니다. v7 설정창 수정과 설치·Pet 추적·업데이트 전체 동작은 실기기 검증이 끝나지 않았습니다.
[Mac 장치 QA](MAC-QA.md)와 [Windows 실사용 범위](WINDOWS-QA.md)를 확인하세요.

## Windows 1.5.0 신규 UI

실제 일반 실행의 한글 입력·포커스·접기/펼치기는 사용자와 확인했습니다. 메시지 필터·이벤트 범위·반응형 WPF 레이아웃·세션 파서·위젯 렌더러 회귀 검사도 통과했습니다. 혼합 DPI·모든 창/작업표시줄 구성과 장시간 동작을 보장하지 않습니다. 신규 창 부착·작업표시줄 UI는 Windows 전용입니다. [상세 검증](WINDOWS-APP-DOCK.md)
