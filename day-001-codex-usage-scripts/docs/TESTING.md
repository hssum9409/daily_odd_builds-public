# 공개 버전 검증 범위

이번 유지보수 릴리즈는 Windows 앱 조작 없이 공통 코어·PowerShell 5.1·실제 Render 함수의 모의 UI 경계와 패키지를 검증했습니다.
Windows 실사용·설치·업데이트·제거는 이번에 재실행하지 않았으며 이전 버전의 기록과 구분합니다.

GitHub HTTP/확인창 응답은 로컬 fixture로 대체했으며 공개 후 실제 다운로드 검증을 별도로 수행합니다.
Mac은 preview입니다. v6까지의 사용자 실기기 진단에서 글자 표시·CLI 발견·사용량 응답을 확인했습니다. v7 설정창 수정과 설치·Pet 추적·업데이트 전체 동작은 실기기 검증이 끝나지 않았습니다.
[Mac 장치 QA](MAC-QA.md)와 [Windows 실사용 범위](WINDOWS-QA.md)를 확인하세요.

## 1.5.4 독립 창 추종

Codex Owner/Parent 연결 제거, 독립 패널의 비활성 Z 순서 정책, 숨김·최소화·복원 및 설정창 열기/닫기를 모의 OS·창 경계로 검사했습니다. 실제 창·message-only HWND 실행, 먹통 재현, 실사용 포커스/한글 입력, 이번 버전의 실제 설치·업데이트·제거는 사용자 요청에 따라 수행하지 않았습니다. 이전 버전의 실사용 기록은 이번 수정의 실사용 검증을 대신하지 않습니다. Mac은 preview입니다.

1.5.1은 세션 로그 증분 처리·현재 대화 매핑·WPF 컨트롤 재사용·동일 프로세스 작업표시줄을 검사했습니다. 실제 일반 실행에서 설정창 창 순서·부분 가림·토큰 표시·한글 입력을 사용자와 확인했습니다. 브라우저 제어 없이 프로세스 카운터로 관찰했으며 CPU 개선율을 보장하지 않습니다.
