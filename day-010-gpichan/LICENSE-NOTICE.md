# 배포물과 제3자 라이선스

지피쨩의 공개 다운로드와 사용 안내입니다. 앱·호스트의 전체 소스 또는 비공개 개발 이력을 공개하는 릴리스가 아닙니다. 이 문서를 전체 구현에 대한 MIT 라이선스 부여로 해석하지 않습니다.

실행에 필요한 Python/Node helper 스크립트와 컴파일된 앱·호스트를 포함합니다. Windows 번들은 Python, Node.js, cryptography, cffi, pycparser 런타임을 포함하며 해당 라이선스는 각 runtime 폴더와 `THIRD_PARTY_NOTICES.txt`에 동봉합니다. Dart 라이선스는 `DART-LICENSE.txt`, Dart 의존성 라이선스는 `vendor` 폴더에 있습니다. Android의 Flutter·플러그인 라이선스는 앱의 개인정보 및 앱 정보 → 오픈소스 라이선스에서 확인합니다.

캐릭터와 홍보 이미지의 제작 방식은 [이미지 제작 안내](https://github.com/hssum9409/daily_odd_builds-public/blob/main/day-010-gpichan/ARTWORK.md)를 참고하세요. Codex와 관련 표기는 호환 대상 설명이며 OpenAI의 공식 제품 또는 승인을 의미하지 않습니다.
