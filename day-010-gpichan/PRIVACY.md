# 지피쨩 개인정보처리방침
시행일: 2026-10-22 · 앱 0.5.1
제작·문의: hssum9409 / hkw96110886@gmail.com

지피쨩은 Android와 사용자의 컴퓨터를 같은 로컬 네트워크에서 연결하는 비공식 Codex Desktop 보조 도구입니다. 자체 계정, 클라우드 백엔드 및 광고 SDK를 사용하지 않습니다. Android QR 인식에는 Google ML Kit를 사용하는 mobile_scanner를 포함합니다.

처리 항목과 목적
QR 스캔을 위해 사용자가 허용한 카메라를 사용합니다. 앱은 카메라 영상을 서버로 업로드하거나 사진으로 저장하지 않습니다. 가속도 센서 값은 기기 흔들기 판정에 사용하며, 흔들기 전달이 켜져 있으면 원시 센서 값 대신 상호작용 이벤트를 컴퓨터로 전송합니다.

연결 주소, 인증서 지문, 장치 식별자 및 연결 토큰을 처리합니다. 연결 정보와 선택한 설정은 기기에 저장하며 연결 비밀은 Android 보안 저장소를 사용합니다. 개인 장치 이름은 장치 승인과 연결 관리에 사용합니다.

승인한 컴퓨터와 암호화된 직접 통신을 통해 세션 제목, 프로젝트 경로, 공개 대화, 공개 추론 요약, 작업 상태를 읽고, 사용자가 입력한 텍스트와 선택한 상호작용을 지정된 기존 Codex 대화에 전달합니다. 앱의 캐릭터가 로컬에서 만든 반응과 실제 Codex 출력은 구분합니다. 컴퓨터의 비공개 원본 추론을 추출하는 기능은 제공하지 않습니다.

외부 서비스와의 관계
Google ML Kit는 QR 입력 영상과 인식 결과를 기기에서 처리하며 이 입력과 결과를 Google 서버로 보내지 않는다고 안내합니다. 다만 SDK 자체는 기기 모델·OS, 앱 버전, 설치 단위 식별자, 처리 지연·오류·기능 사용 등의 진단 및 사용 지표를 Google에 HTTPS로 전송할 수 있습니다. 따라서 지피쨩 전체를 외부 통신이나 진단 수집이 전혀 없는 앱으로 안내하지 않습니다. 이 SDK 데이터의 처리·보관·권리 행사에는 Google 정책이 적용됩니다.
Google ML Kit 개인정보 안내: https://developers.google.com/ml-kit/terms
Android SDK 수집 항목: https://developers.google.com/ml-kit/android-data-disclosure

기존 Codex Desktop이 모델 처리에 사용하는 OpenAI 등의 서비스에는 해당 서비스의 약관과 개인정보처리방침이 적용됩니다. 지피쨩이 클라우드 백엔드를 갖지 않는다는 사실이 Codex의 모델 처리까지 오프라인이라는 의미는 아닙니다. 앱은 Codex 인증 토큰을 휴대폰으로 복사하도록 요구하지 않습니다.

보관과 삭제
Android의 대화·작업 표시와 전달 기록은 실행 중 메모리에서 처리하며 자체 대화 보관 서버를 운영하지 않습니다. 설정에서 연결을 잊으면 저장한 컴퓨터 연결 비밀을 삭제합니다. PC의 장치 승인 해제와 로컬 데이터 삭제는 PC의 Gpichan CLI에서 별도로 진행합니다. 앱 제거는 기존 Codex의 대화나 PC 파일을 삭제하지 않습니다.

PC는 승인 장치, 인증서, 호스트 설정과 전달 중복 방지에 필요한 기록을 로컬에 보관합니다. 진단 로그에는 대화 원문·연결 토큰을 기록하지 않도록 제한합니다. PC의 설치 제거는 사용자 연결 데이터를 보존하므로 완전 삭제를 원하면 사용 가이드의 로컬 데이터 삭제 절차를 따르세요.

권한과 선택
카메라는 QR 연결에 필요할 때 요청합니다. 흔들기 감지와 터치 전달은 설정에서 끌 수 있습니다. 최초 연결은 컴퓨터에서 장치를 승인해야 하며 장치 승인을 해제하면 다시 연결할 수 없습니다. 승인된 장치에는 실제 개발 작업 정보가 표시될 수 있으므로 본인 기기만 승인하세요.
