합성 통합 검사는 인증서 지문 불일치·미인증 요청 거부, 최초 승인, 세션 간 오전달 방지, 중복/오래된 입력 차단, 연동 OFF, 승인 장치 재연결·해제를 포함합니다. 부하가 큰 병렬 실행에서 초기 20초 시작 제한을 넘긴 적이 있어 검사 시작 제한을 60초로 조정하고 직렬 재검사했습니다. 최종 native의 관찰된 시작 시간은 약 6.98초, kernel은 약 3.84초였습니다. 평균 성능이나 상한을 보장하는 수치가 아닙니다.

## 기존 Codex Desktop에서 실제 확인

Windows의 **Codex Desktop 26.1016.8120.0**, 설치 CLI **0.163.0-alpha.11.1**에서 기존 Desktop 소유자의 IPC 연결과 기존 세션 목록·이름·공개 메시지·모델 설정 읽기를 확인했습니다.

0.5.1 native CLI에서 현재 진행 중인 기존 대화에 식별 가능한 테스트 입력을 Steering으로 전달했습니다. 그 입력이 실제 사용자 메시지로 도착했고, 같은 대화의 모델이 다음 발언에서 식별자를 확인하며 원래 개발 작업을 계속했습니다. 별도 App Server나 대화를 만들지 않았습니다.

로컬 타임스탬프 기준 입력 생성 → Desktop 접수는 약 **0.71초**, 입력 생성 → 실제 후속 모델 발언 기록은 약 **5.11초**였습니다. 이는 이 PC에서 한 번 관찰한 결과이며 네트워크·화면 표시 지연 전체를 측정한 값은 아닙니다. 1~2초 반응을 보장하지 않습니다. 이번 실제 확인은 CLI Steering 경로이며 Hook·Queue·유휴 새 Turn의 전 조합을 다시 측정한 것은 아닙니다.

## 배포물 검사

APK/AAB는 개발 debug 키 대신 별도 배포 키로 서명합니다. APK의 ID/버전, 등록된 리그 36개 파트와 들여다보기 6개 파트의 원본 해시, 개인정보 안내 원문 일치, APK/AAB 각각의 64비트 네이티브 라이브러리 12개의 16KB 정렬을 확인했습니다. 최종 공개 AAB는 서명과 bundletool 구조 검증을 통과했습니다. 개발용 native 심볼과 ProGuard map은 비공개로 분리했고, 다시 서명하기 전후 보존된 앱/metadata entry 363개의 내용이 일치했습니다. 개발자 홈 경로·키·장치 등록·개인 세션·전체 개발 소스와 테스트 fixture를 공개 런타임에서 제외합니다. 비공개 심볼은 APK/AAB별로 따로 보관합니다.

## 미검증과 제한

이번 버전의 **실제 Android 휴대폰 Wi-Fi 연결·키보드·내비게이션 바·센서** 검사는 미실행입니다. 자동 UI 검사나 이전 개발 버전의 실제 휴대폰 연결을 이번 버전 실기기 결과로 대체하지 않습니다. Android 35 에뮬레이터 시도에서는 호스트 메모리 부족과 System UI ANR이 있어 그 화면을 정상 동작 증거로 사용하지 않았습니다.

macOS는 **실기기 미검증 preview**입니다. 설치·launchd·로그인 자동 시작·기존 Desktop 연결·Gatekeeper와 네이티브 Mac 빌드는 후속 검증입니다. Mac 설치 스크립트·실행 권한·LF 줄바꿈·manifest 해시와 소켓 보안 판정은 검사했지만 Mac에서 실행한 결과는 아닙니다. 정확한 Dart SDK 3.13.5 및 안내된 외부 런타임이 필요합니다.

이번 Windows Setup은 이 PC의 Smart App Control을 변경하지 않은 상태에서 설치·업데이트·제거를 통과했습니다. 과거 0.5.0 개발 Setup이 같은 PC에서 차단된 기록과 구분합니다. 실행 파일은 여전히 **미서명**이며 다른 PC나 다음 OS 평판 판단에서 허용될 것을 보장하지 않습니다. 실제 재부팅/로그인 자동 시작은 이번 검수에 포함하지 않았습니다.

Google Play 게시·프로덕션 승인, 유료 코드 서명, Mac notarization은 완료하지 않았습니다. Hero·기능 그림은 AI 홍보 컨셉 이미지이며 실제 화면 캡처가 아닙니다.
