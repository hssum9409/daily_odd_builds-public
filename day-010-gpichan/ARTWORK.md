# 지피쨩 공개 이미지

`assets/gpichan-hero-original.png`와 `assets/gpichan-features-original.png`는 기존 지피쨩 SD 원화를 참조하여 AI 이미지 생성 도구로 제작한 **홍보 컨셉 일러스트**입니다. 기기와 작업 화면은 기능의 관계를 설명하는 그림이며, 실제 앱 스크린샷이나 실기기 검증 자료가 아닙니다. 이미지 안에도 이 구분을 표기했습니다.

참조 디자인은 사용자가 지정한 가슴 프레이밍용 지피쨩 SD 원화입니다. 흰색 단발과 파란 눈, 검정·파랑 삼각 머리핀, 흰 재킷과 검정·파랑 의상을 기준으로 삼았으며, Interactive v7의 현재 캐릭터 모습과 대조했습니다. 기존 캐릭터 파트나 애니메이션 리그를 변경한 자산이 아닙니다.

`assets/gpichan-icon-original.png`는 같은 원화를 참조한 얼굴 중심 앱 아이콘입니다. `assets/gpichan-icon-master.png`와 크기별 PNG는 하나의 원본에서 크기만 조정했습니다. 히어로와 기능 이미지의 1280×800 WebP도 원본의 비율을 유지하여 축소하고 무손실 WebP로 저장한 웹용 파생물입니다.

표현한 기능은 Android 캐릭터 터치·쓰다듬기·간식·흔들기와 기존 Codex Desktop 대화 선택·작업 출력 확인·Steering·Queue·텍스트 입력입니다. 실제 지원 환경과 검증 범위는 제품 문서를 기준으로 확인할 수 있습니다.
