# o'clock catcher · 이미지 안내

0.1.2에는 hero, 홍보 이미지와 기능 설명 이미지를 추가했습니다. 세 이미지는 OpenAI 내장 이미지 생성 도구로 새로 제작한 콘셉트 아트이며 실제 제품 캡처가 아닙니다. 기존 제품의 아이보리·검정·버밀리언 색상과 정각의 한 순간을 잡는 주제를 사용했습니다.

요청에 따라 GPT-6 Astra / High 작업자가 이미지 도구를 직접 호출했습니다. Fast 설정을 선택하지 않았으며, 도구에 이미지 backend의 과금 등급을 확인하는 항목이 없어 별도의 비-Fast 과금 등급을 검증했다고 주장하지 않습니다.

- hero-v0.1.2.webp: 대표 hero 및 포털 표지.
- promotion-v0.1.2.webp: 홍보 이미지. JPEG 1200×630은 링크 공유 미리보기용이며 원본 비율을 유지해 여백을 더했습니다.
- features-v0.1.2.webp: 준비 → 한 번의 경합 → 우승 전시 흐름과 지연 테스트를 설명합니다. 시간과 +58ms는 설명용 예시입니다. 실제 순위는 RTDB 서버 기록을 기준으로 판정합니다.
- desktop.webp, latency-test.webp, mobile.webp: 실제 운영 HTTPS 사이트의 Chromium 브라우저 캡처. mobile.webp는 데스크톱 브라우저의 모바일 너비 검증이며 실기기 캡처가 아닙니다.

생성 아트는 외부 작가·브랜드의 자산을 가져오지 않고 이 제품을 위해 제작했습니다. 제품 소개·링크 공유에 사용하도록 제공합니다. 생성물의 독점성이나 별도 상표권을 보장하지 않으며, 이미지 공개는 비공개 앱·서버 소스에 대한 라이선스 부여가 아닙니다. 타사 구성요소의 라이선스는 THIRD-PARTY-NOTICES.txt를 따릅니다.
